维护协议

与 CLAUDE.md §1 同语义;冲突以本节为准。一个 session 默认完成当前活动 Phase 的全套未阻塞任务。

时点动作
开始前grep 本文件 #session-log + status: "doing"/"blocked" 定位上次停点;确定活动 Phase = 最早含 todo 的 Phase(blocked Phase 永不自动认领)。
认领该 Phase 可做任务全部 todo→doing + 填 session_date;依赖未满足改 blocked + notes 写 blocked_by:。
完成单任务一任务一 feature commit(英文 conventional)→ 状态改 done + 回填 commit(7 位真实 hash)+ notes(What+Why 1-2 句)。
codex 门凡有代码编写的任务,commit 前先过 codex review(修完 P0/P1/P2 再 commit;撞限流 → /code-review high);docs/ledger-only 豁免;codex 不可用须上报 owner,严禁静默跳过。
结束 sessionPhase 全 done(或确实无法继续)后,一次 docs-only commit 在 SESSION_LOG 顶部追加覆盖整个 Phase 的条目 + 修订记录加一行。
改决策边界先新增 docs/decisions/*-amendment-YYYY-MM-DD-*.md 再改代码;无 amendment 的行为差异 = 违规。
报告「完成」前:本文件必须已改(真实 commit hash + 改了什么)。只改 localStorage 不算项目进度。 push / test 集 look-once / 数据摄取 / live 激活一律 owner-gated。
