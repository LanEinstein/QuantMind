## 3. 消融臂(基线 + 止损叠加,其余逐字节相同)

### 3.1 触发器(冻结;Codex 决策 1)

对交易日 T、证券 c:**flag(c,T) 当且仅当 c 的过去 20 个交易日复权收益
(`adjc[T]/adjc[T−20] − 1`,后复权 close×adj_factor 同日口径)在当日全市场横截面中
排名分位 ≤ 0.10**(`rank(method="average", pct=True)`,并列取平均秩)。

- 横截面 = PIT priced panel 工作宇宙:剔 `.BJ`、剔已定案的 78 只复权失准证券;
  当日不足 20 根历史的证券不可被 flag(计数披露)。
- **逐交易日检查**(非仅调仓日)——P-B 硬触发语义;
  百分位形式跨市况尺度不变:系统性普跌中低 beta 红利股不会落入底 decile,
  sleeve 按设计用现金 buffer 扛 beta,止损只打**个股异常断裂**。

### 3.2 执行语义(冻结)

- 持仓中 flagged → **T+1 开盘强制卖出**(冻结循环的 zipline 屏障,决策于 T 收盘后);
- flagged 期间**禁止买入**该证券(防止"价格跌→dv_ratio 升→规则更想买"的卖了又买循环);
- 与基线决策的合成:先算基线 `decide_day` 决策,再追加持仓中 flagged 的强制卖单
  (基线已卖的不重复)、剔除当日对 flagged 证券的买单;
- 止损腾出的槽位自然等到**下一调仓日**再补(期间持现金)。

### 3.3 工程缝(冻结)

`run_backtest`/`run_gate_backtest` 增加可选 `decide_fn` 参数,**默认= 现行 `decide_day`,
默认路径字节不变**(回归测试断言);消融的止损合成只存在于消融脚本自己的包装函数里,
不改任何共享决策逻辑。

## 4. 判据(冻结;Codex 决策 2)

先看事件底线:**已执行的止损卖出成交笔数 < K = 15 → 裁决 INSUFFICIENT-EVENTS,封存**
(不调 K、不放宽触发器重跑)。

事件足够时,**ADOPT-SIGNAL 当且仅当同时满足**:
1. `MDD_消融 ≤ MDD_基线 − 0.02`(降幅至少 2 个百分点);
2. `net_消融 ≥ 0.80 × net_基线`(净盈保留至少八成)。

否则 **NO-ADOPT**。三种裁决都封存本研究;不存在"接近就算过"。

## 8. 已知限制(运行前承认)

1. 基线 fills 极少(SLV-1 科学门 9/125)——止损事件可能不足,这正是 K 底线存在的原因;
   INSUFFICIENT 也是有效知识(该书的持仓很少进入全市场底 decile,本身是防御性证据)。
2. 触发器只覆盖"相对弱势"这一种"反常";财务造假停牌等无价格路径的反常不在本定义内。
3. 止损后持现金到下一调仓日是保守选择,可能放大净盈损失——如实计入判据 2。
4. 面板首 20 个交易日(约 20150202 前)无 flag 能力(不足 20 根历史),披露。
