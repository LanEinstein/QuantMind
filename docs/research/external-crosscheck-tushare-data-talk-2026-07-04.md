## 2. 对当前决策点的三点启发

### 2.1 困境的性质:不是"找不到",是"这批数据里本来就没有"

四门竞技场(DSR/SPA/Romano-Wolf/选拔制 placebo)四轮 + DS 两刀,一直在精准报告同一事实:**在人人可买的 Tushare 量价+财报数据上,用公开逻辑构造的排名因子,相对随机组合没有可认证的边**。这正是文章说的"同质化数据+同质化逻辑 → 策略扎堆 → 信号失效"。我们的门不是太严——它在如实测量拥挤度。

### 2.2 owner 两条待决路径:文章支持"不二选,分角色"

- **sleeve(防御宇宙过滤 + 现金 buffer)= 文章的"低拥挤稳定数据稳住收益底盘"**。D1/D2 双重验证过滤器承重;这条腿的价值来源是风险性质,不需要排名 alpha,不受拥挤度侵蚀 → 文章逻辑下最该先落地。
- **分析师修正动量 = 排名层唯一未被证伪、机制不同(信息流非价量)的候选**。文章明说它"只适合辅助"→ 即便 D2 式测试过门,预期应校准为薄边+辅助权重,不是逆转 DSR 困境的救世主。**AP-0.5 的算术结论(SR_req 2.67 候选无关不可达)不因换因子而改变,认证仍只能走前向**(2026-07-04 certification rearch amendment)。
- 工程现状:`scripts/factor_research/analyst_momentum_{spec,ablation}.py` + 对应 tests 脚手架已在工作区(untracked),就绪待 owner 定向。

### 2.3 警惕文章的"AI 因子工厂"叙事——对我们是陷阱

文章鼓吹 LLM 自动挖因子/全自动因子工厂。但我们的账本(N=2419 trial)和 AP-0.5 证明:**在同一批数据上加大挖掘次数只会加深多重检验债,让本已不可达的认证门更加不可达**。数据飞轮的正确读法是**扩数据的正交性,不是扩挖掘的次数**。文章自己的"垃圾进垃圾出/算法放大数据优劣"论断反而支持这一点。

## 3. 若 owner 想继续找排名边:PIT 权限内未开采序列(按机制正交性排序)

前提:全部走同一套四门 + 账本继续累计 + SELECTION 框架(排名/宇宙过滤,严禁做成择时 overlay)。

1. **`stk_holdertrade`(重要股东增减持)**——事件型信息流,与反转/质量正交;原 C2 计划已排(owner-gated 摄取)。
2. **`top_list`(龙虎榜)+ `block_trade`(大宗交易)**——行为/资金结构数据,主力意图纲领自然延伸;须吸取批 A/QGR-4 教训:做 SELECTION 不做 EXIT/择时。
3. **`share_float`(限售解禁)**——供给冲击事件,机制干净,文献先验充分(解禁前抛压),符合原则 #2(文献先验 → 从零验证)。
4. `moneyflow`(个股资金流)——曾有意降级(§3.6 陷阱);重启须先解决单边标记口径问题。

**诚实 caveat**:以上在 Tushare 上人人可买,不是文章意义上的"独家另类数据"(卫星/流水/物流我们拿不到)。即便开采,预期仍是薄边+辅助;真正的护城河是我们的处理纪律与反过拟合体系,而非数据独占性。
