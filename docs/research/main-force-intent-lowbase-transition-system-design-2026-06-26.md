## 3. 诚实的核心张力:证据评审(去玄学)

> 四个并行研究 agent 广泛联网调研(学术 SSRN/arXiv q-fin + 实务 + 券商研报),结论**强烈通缩** A 股主力/打板民间叙事。完整出处见 §13。

**3.1 真有 OOS 证据的边 = 逆向 / 防御,不是「追主力」**

- **短线反转**(−近 1 月收益)= A 股最稳健、最可复现的截面效应(中国**只有反转、没有动量**于此 horizon);但它是**逆向**的——叫你**别追近期大涨股**,与「买正在被拉的票」相反。✅ 与 QGR-3 幸存因子一致。
- **彩票/MAX & IVOL 过滤** = 强证据,剔除暴涨投机名(也正好执行 owner「不追涨高位」)。
- **异常/缩放换手**(size-中性化后)= 分歧/过度关注过滤,偏低/收缩换手。
- ⚠️ 上述四者**全部 size-纠缠**(集中在微盘/壳区)→ **必须 size/行业中性化 + 删最小 30%**,否则就是 round-1..4 的覆辙。

**3.2 主力/打板叙事 = 弱/玄学(owner 小作文的表层)**

- **炸板=吸筹 / 封单强度 / 隐性吸筹避龙虎榜 / 打板** 这一簇 = **无 OOS 支持**;炸板最佳证据指向**派发**;账户级数据显示大户**涨停日买、次日卖**,其净买入预测**反转**。
- **「高换手但不上龙虎榜 = 吸筹」无任何学术/OOS 支持,且如表述般不可证伪**——「隐性吸筹」永远是票涨了之后才贴标签(教科书级 hindsight)。机理上,亚阈值高换手与派发/洗盘**长得一模一样**,符号未定。
- **买涨停 = 基本不可成交**(一字板 ~9.2%、T+1、封板);「收盘/次开买入」回测是幻想成交;打板回测在 25bp 滑点下 **+151%→+18%** 崩塌。

**3.3 北向「聪明钱」数据已死(对 owner『资金定主线』是硬约束)**

- 北向**实时**(~2024-05)与**个股日度持股**(~2024-08-19 改季度)披露**已停**;`hk_hold` 日度 ~2024-08 断,转季度。→ 历史上**强**的「异常北向持股(AHVR)」因子,**现在不是 live 可交易信号**。只能作历史研究因子 / 季度滞后 tilt,**绝不能**当 live 日度选股器。

**3.4 事件 alpha:最干净的是『减持』作负向排除**

- **减持(机会型快卖)= 最干净的可交易事件信号 → 负向漂移 + 崩盘预测**;**用作硬排除/惩罚**。
- 增持/回购/外资进十大流通股东/换帅/国资入主 = **作买入信号弱/玄学**;换帅平均符号**为负**(高管动荡→崩盘风险)。多数事件「alpha」是**披露前泄漏**,到可公开行动的 `ann_date` 已消失。

**3.5 主题/概念成分 = 严重 look-ahead 陷阱**

- 供应商常在票**涨了之后**才把它加进「AI 概念」(成分对涨幅**内生**),制造假主题动量。→ 概念成分**只能作资格/上下文,绝不作收益预测**(= owner『产业定方向』的正确用法)。

**3.6 `moneyflow`(资金流)= 已记录陷阱**

- 日度大单/主力净流入符号在同花顺/东财/Tushare 间**翻转**;Shenoy-Zhang(2007):订单失衡**无预测力、仅同期**。→ **本方案不接入 moneyflow**(codex Round-1/2 均强烈反对)。

**3.7 诚实总判**:**不存在**已发表的、严谨的、日频可算的「主力意图 → 预测上涨」模型;可测之处要么仅日内、要么符号相反。owner 小作文的**表层**(抓主力拉升、炸板吸筹、买板)= **整个 A 股量化空间里最易过拟合的框架**。

## 5. owner『低位预判大涨』如何被真正兑现

owner 真正想要的不是「同日开盘抓当日涨停」(日频 EOD 数据**诚实地做不到**),而是「**在低位提前预判后面的大涨**」。映射:

> **as-of T−1 收盘** → 排序权威(逆向+质量+主旋律资格)出候选 → **低位结构转折叠加层**确认「长期缩量低位 base + 首次放量收复」→ **T+1 入场(若可成交)** → 持有 5-10td 捕获前向波动 → 破位/到位卖出。

这正是小作文作者**剥离叙事后的真实行为**:在战略赛道、**低位**、有质量背书、**首破低位 base(不追高)**、持有、到位/破位卖出。「只有外资有此手法」是**叙事**;行为是稳健的。**我们兑现行为,证伪叙事。**

## 6. 测试协议:时序 MASK「伏击」模拟器(owner 点名要的)

> 目标:as-of 某日,只见过去、不见未来,模拟真实操盘,诚实回答「系统能否在低位预判后面的放量大涨」。嫁接现有冻结竞技场,不另起炉灶。

### 6.1 PIT as-of 快照(无未来泄漏)
- 每行两时间戳:`effective_date`(数据描述的期/日)+ `knowledge_date`(可知时点:公告/收盘/发布);**选 `knowledge_date ≤ cutoff(T−1 收盘)`**。
- 基本面/事件键 `ann_date`(非期末);复权因子 **as-of pin**(只用 T 时已知的因子);幸存者无偏宇宙 + PIT-ST(`namechange`)+ 可交易 mask(停牌/封板**移出可买集**,持仓名保留终值)。
- **泄漏门 = future-NaN 投毒测试**:把所有 `knowledge_date > cutoff` 数据置 NaN 后重算,picks 必须**逐字节相同**;变了 = 有人读了未来。

### 6.2 可交易标签(三重屏障,不是「命中涨停」)
- 三重屏障(波动缩放、非对称:大上轨/紧下轨/短垂直);**入场 = T+1**(经 `gate_backtest` harsh-fill,非自定义 VWAP 幻想);**出场重定价到首个可成交价**;丢弃一字板/封板/停牌;T+1 结算;≤10% ADV。
- **不用**原始「命中涨停」标签(基本不可交易)。

### 6.3 晋级判据层级(codex Q-3:冻结,不破 QGR-2)
- **PRIMARY(唯一晋级门)= QGR-2 事件循环净 P&L + MDD≤8%**(冻结竞技场 + 成本/撮合/涨跌停约束 + 非清零账本)。
- **DIAGNOSTIC(诊断,绝不用于晋级)= precision@5 / 放量大涨命中率**;命中率**分母必须 fills-aware**(仅可成交/已入场名,见 §6.6),否则漂移成「预测到但买不到」陷阱。

### 6.4 反过拟合(复用现有门)
- CPCV **按日期分组**(绝不把同日截面拆进 train/test);**不把重叠拼接路径当独立样本喂 DSR**(`cpcv.py:23` 已警告固定策略零路径离散)。
- **DSR>0.95 / PBO≤0.05 / Hansen SPA / Romano-Wolf / BHY-FDR** + **非清零 trial 账本**(改判据**不清零** mining 债)。

### 6.5 制度分层(杀 size-tilt 幻觉)
- precision@5 / 每笔净payoff / **MDD** 分 {牛/熊/震荡} × {高/低波} × {大盘/小盘领涨} × {主题 on/off} 报告;**要求逆境制度不毁灭**(非负、不破回撤),不只看均值。**这是 R5「+2.68% 一半来自 size tilt」教训的直接防御。**

### 6.6 **强制 ablation + placebo(codex Q-A/Q-D 第一要务)**
> 低位结构转折叠加层「不排序所以不会偷动量 alpha」**不成立**——它仍是**可交易选择过滤器**,能偷动量暴露。必须自证。

三臂对照(**同一逆向排序器、同一通过率/换手、同一撮合、同一持有窗**):
1. `ranker alone` = {rev_1d, max_5d, turn_spike}
2. `ranker + 低位结构转折门`
3. `ranker + 纯突破 placebo 门`(去掉缩量/守支撑/长 base,只留首破区间/放量/非涨停/未延伸)

判决:
- 若 **placebo 追平或超过低位门** → 故事是假的,叠加层只是**动量择时** → 丢弃或更名为「突破择时」。
- 若 **低位门成本后超过 ranker-alone 与 placebo 两者**(更低换手或更优回撤)→ 只赢得**窄声明**:「择时过滤改善了实现」,**不是「主力 alpha」**。

### 6.7 前向确认(唯一能上线的判决)
- git 冻结 + 预留**只看一次**的真前向/lockbox 窗 + go-live **真管线 shadow replay**;低 DSR/勉强显著 = **provisional**,须前向确认。**sim 暂停贯穿至此。**
