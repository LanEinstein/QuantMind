## 2. owner 决策(2026-06-19)

**train_val / test 数据划分可在不同因子/策略搜寻方案之间复用。**

**理由(owner 原话转述)**:每一次因子/策略搜寻是**相对独立的实验**。只要
① 不拿测试集结果去指导搜寻,且 ② 测试期计算严格 PIT(只用测试期数据、ann_date/in-out
date/publish<d 等 as-of 门控),就**不构成 look-ahead 数据泄露**。

### 直接后果:解锁 R2-6
- **不再等前向封存窗口**;R2-6 判定**直接跑在既有锁定测试集**
  `config/research/test_set_lock.json`(**2025-06-04 → 2026-06-12,250 交易日**)。
- round-2 计划 §2 / §11 的「测试集已烧、等前向数据」设定**被本决策放宽**。
- 该锁定测试集此前已被 **round-1 终选策略评测过 1 次**;本轮 benchmark-relative 是
  **第 2 个**被该测试集评测的策略。

## 3. 诚实保障(owner 放宽 ≠ 放弃诚实 —— 四条全部保留,不可减)

放宽的只是「必须用前向新窗口」这一条;**护测试集 = 保证真盈利的手段**,其内核纪律全留:

1. **冻结-再读纪律(firewall)**:策略**先 git 冻结(commit,记 hash)→ 再读测试集**。
   开发期(R2-4/R2-5)对 test 零触碰;测试集只有一个 sanctioned 读取路径(R2-6 的认可
   reader),且策略须先冻结。沿用 round-1 commit-before-test firewall +
   `LockedSplit.assert_not_test` 守门 + 基准侧输入开发期 < test_start 流式过滤。

2. **多重检验 deflation 不变(累计 N)**:R2-4 搜索内 DSR(**主门 ≥0.95**)/ PBO
   (≤0.5 硬 / ≤0.2 目标)/ SPA 按**累计 N**(含失败 + 人工中止变体)deflate;预声明
   `round2_experiment_manifest.json` 枚举全自由度,`n_trials` = 累计而非仅存活。

3. **透明披露(测试集第 2 次评测)**:R2-6 报告须**显式写明**:
   「本锁定测试集此前已被 round-1 策略评测 1 次,本 benchmark-relative 是第 2 个被该
   测试集评测的策略 → **跨策略多重检验存在但有界(2 次,非数百次)**」。
   不假装这是处子 OOS;诚实标注复用的代价。

4. **四门判据不放宽**(owner 锁定,全过才 PASS):
   - ① 扣成本净收益 > 0
   - ② 跑赢沪深300:累计超额 ≥ 0
   - ③ 最大回撤 ≤ 15%
   - ④ 年化夏普 ≥ 0.5

   **IR / TE / 主动夏普 = 仅补充披露,非替换门**(严禁悄悄拿 IR 当"过门替身")。
