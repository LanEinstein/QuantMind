## 1. 一句话结论

在**从未触碰的锁定测试集**(2025-06-04 → 2026-06-12,250 交易日)上,终选策略
**扣成本净赚 +5.48%、回撤仅 7.78%、夏普 0.54**,但**跑输沪深300 16.36 个百分点**
(同期 CSI300 +21.84%)。四条 PASS 门槛 **3 过 1 不过 → 判定 FAIL**。

**这是一个诚实的样本外失败,且 Phase 3 的诚实门(DSR=0.066 不过 0.95)事先就警告了它。**

→ Phase 4 一次性读 test、扣成本回测、判 PASS/FAIL。

## 4. 诚实失效分析(为什么 FAIL)

1. **样本外 ≠ 样本内,且 DSR 事先警告过。** Phase 3 的 DSR=0.066(远不过 0.95)
   诚实地说:在 512 次搜索去偏后,样本内 +69.68% 超额的『显著性』不成立 ——
   它可能是被选择偏差 + 特定 regime 抬高的。**锁定测试集证实了这一点**:样本外超额
   直接翻成 −16.36%。**反过拟合门没有失职 —— 它正确预测了 val 结果脆弱,我们也没有
   把一个会跑输指数的策略上线。** 这是诚实纪律『起作用』的范例,不是失败的借口。

2. **regime 错配:测试期是大盘指数强势年。** CSI300 在 2025-06→2026-06 涨 +21.84%
   (强势大盘/趋势行情)。终选策略是**防御型『避开投机』组合**(低波 + 低换手 + 价值 +
   流动性,动量归零),结构上**在大盘领涨的牛市里天然跑输 cap-weighted 指数**。它确实
   赚了正收益(+5.48%)且回撤小(7.78%),但跟不上 +21.84% 的指数。

3. **long-only top-5 对指数是『基准无关』的。** 5 只等权多头篮子无法跟踪 300 只市值
   加权指数。在指数靠少数大票拉动的行情里,任何不押那些大票的分散组合都会落后 ——
   这是构造层面的、而非因子层面的差距。

4. **2026 衰减。** 2025-H2 还能跟(+10.67%),2026-H1 转负(−4.69%),把累计拖低。
   防御因子在 2026 上半年的 A 股行情中没有得到奖励。

## 5. 我们确实学到了什么(非粉饰)

- **现役动量权重确被证伪。** 动量 incumbent(top-5 按高 ret_20d = 现役 `FACTOR_WEIGHTS`
  的押注)样本内 −93.86%;我们的替代虽未过『跑赢指数』门,但**现役那套同样不该作为
  指数 beater 上线**。本专项最稳的结论 = **现役 `momentum_20d 0.40` 未经验证且方向存疑**。
- **横截面 IC ≠ 跑赢市值加权指数。** 7 因子的截面 IC 都强(t 从 −12 到 +6),但截面选股
  优势**不等于**用 long-only top-5 跑赢 cap-weighted 指数,尤其指数靠大票领涨时。这是
  目标函数的错配:我们优化的是截面 rank,考核的是相对指数超额。
- **诚实门有效。** DSR 提前标红 → 测试集证实。**护住测试集 = 保证报出来的盈利是真的;
  这次它诚实地说『没有真的指数超额』。**

## 6. 下一轮方向(诚实、可执行;**严禁回头改测试集口径**)

**测试集已『烧掉』(契约):** 本窗口(2025-06→2026-06)= 最近一年真实数据,已一次性用于
评估,不可再用于任何迭代。**且它本就是最新的数据 —— 没有更新的窗口可切。** 诚实约束:
我们几乎用尽了全部可用历史做开发。真正干净的新 OOS 窗口要么(a)等新数据积累一段时间,
要么(b)重做开发、从一开始留出一段更早的从未用过的窗口(但 2015-2025 已全程入开发,
难找未污染段)。

**方法层面(若 owner 决定继续)**:
1. **改成基准相对/多空构造**:long-only top-5 无法跟指数;index-neutral 或 long-short
   叠加(对冲掉 beta、只赚 alpha)才可能在牛熊都跑赢指数。**这是最根本的修法。**
2. **基准感知的因子中性化**:对行业/市值相对沪深300 做中性化,避免在大盘领涨时系统性
   落后。
3. **加趋势/动量 sleeve 做 regime 适配**:搜索在 2015-2025 上把动量归零(样本内它伤害
   收益),但这让组合**只会防御**;regime 条件化的动量/趋势分量可能在牛市跟得上(代价 =
   自由度上升 → 过拟合风险,须更严的 DSR/PBO)。
4. **重定义成功判据(可与 owner 商定)**:本策略**通过了**绝对收益 + 风控的三门(净 +5.48%、
   回撤 7.78%、夏普 0.54)。若目标是**风险调整后的绝对回报**(而非指数超额),它是一个
   合理的防御型 book;但按 owner 当前锁定的『跑赢沪深300』门,它 FAIL。

## 7. 局限 & 交叉确认

- **portfolio-sort 近似**:本回测扣了 A 股往返成本(~0.16%/换手),但**未建模 T+1 / 涨跌停
  at-fill / 分板块滑点**。强烈建议用 `backend/backtest/` 全引擎复跑确认。**但注意:全引擎
  只会增加摩擦 → 净收益更低 → 超额更负 → FAIL 更稳固**,不可能把 FAIL 翻成 PASS。故本
  判定对额外摩擦稳健。
- **基准口径**:Phase 4 前已把基准腿修正为**与策略同 horizon(5 bar)逐期对齐**
  (`_benchmark_leg`),消除末期未计入的偏差;−16.36% 的差距远大于任何基准口径的边际,判定稳健。
