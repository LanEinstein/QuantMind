## 发现 1 ⛔ 分散**伤害**(codex 核心假说被数据证伪)

槽数 5→50:**MDD 上升 56%→63-66%、净盈下降 571k→281k、DSR 下降 0.0059→0.0032**。`diversification_mdd_fell=false / dsr_rose=false`,SPA p=0.464、Romano-Wolf 全 not-rejected。

**机制(A 股市场结构)**:① **股灾是全市场的**(2015/2018 相关性→1)—— 多铺股票在崩盘里**毫无保护**,5 名和 50 名一起崩 ~60%;② 反转 alpha **集中在最超卖的头部名**,分散到 20-50 名引入弱反转信号,**稀释 alpha**;③ 更糟:最超卖的头部名崩盘后**反弹更强**(反转=崩盘恢复 alpha),集中在头部 → **崩盘恢复更快 → MDD 反而更低**;分散稀释反弹 → MDD 更深。**∴ 分散 = 无崩盘保护 + 稀释 alpha + 削弱反弹恢复 = 严格更差。**

## 发现 2 ✅ 现金 buffer **确实**控回撤(P-E 直觉被印证)

N=5 固定,降暴露 0.72→0.30:**MDD 56%→31%,~正比于暴露**(未投现金不崩)。`buf40_5`(实现暴露 0.30 = ~70% 现金)= **+294k 净盈 + 31.4% MDD**,在净盈和 MDD 上**双杀 CSI300**(+176k/46%)。**这是唯一控 MDD 的杠杆,且是组合/暴露层(P-E 现金 buffer),不是选股闸层、不是分散。**

> **caveat**:buffer 是**风险缩放器**(MDD 和净盈~正比缩,Sharpe/DSR ~恒定 0.0052),**不是 alpha 改良器**——它沿同一(弱)Sharpe 线移动,换 MDD/return 比例,不改风险调整边。

## 发现 3 🔑🔑 **没有任何配置过 DSR≥0.95**(alpha 才是绑定约束,非容器)

全配置 DSR ~0.003-0.006 ≪ 0.95;**eq_5(≤5 集中)DSR 最高(0.0059)** —— ≤5 集中是风险调整最优的槽数,但即便最优也远不过门。容器(槽数/buffer)只在弱 Sharpe 线上换 MDD/return 比例;**绑定约束是 ranker 的风险调整 alpha 太弱**(扣 2387 累计 mining 债后不可辨于运气)。

## 诚实判读(三问的数据答案)

1. **codex「≤5 是绑定约束,分散到 20-30」= 被数据证伪**:分散在 A 股**伤害**(全市场崩盘 → 分散无保护,只稀释集中反转 alpha + 削弱崩盘反弹)。
2. **你的 P-E 直觉被印证**:**≤5 集中是对的(最高 DSR)**,控 MDD 的杠杆是**现金 buffer**(组合层),不是分散、不是 EXIT。「≤5 + 控回撤」**不矛盾**——`buf40_5` 在 ≤5 集中下把 MDD 控到 31%(代价是净盈也缩到 +294k)。
3. **但 codex「回撤是组合层问题」half-right**:对(buffer 控 MDD)、但具体机制是**降暴露**而非**分散**;codex「换 ranker / 加槽」half-wrong。
4. **真正的开放问题 = 选股 alpha 质量,不是容器**:容器问题已答(≤5 + 现金 buffer = MDD 控制最优)。**没有配置过 DSR → 纯反转 ranker 在任何容器下都不是 deflation-survive 的风险调整边**。**研究重心应转向把选股 alpha 做强(更强/更正交的 alpha),而非继续调风险容器。**

> **DSR caveat(重要)**:2387 deflation = round-1..4 累计 mining 债的**保守**惩罚(为之前所有无关失败搜索扣分)。eq_5 的 raw Sharpe 未必差,是重 deflation 压低了 DSR。**真仲裁 = look-once 前向(未花,owner-gated)**——deflation 可能过度惩罚了这个 ranker。但在 train_val + 非清零纪律下,如实报「不过门」。
