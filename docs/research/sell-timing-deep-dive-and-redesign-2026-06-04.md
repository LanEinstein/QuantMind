# 卖出时机深度调研与机制重设计(2026-06-04)

> **出处**:owner 2026-06-04 指令——「我们的目标是盈利,而不是止损。昨天 5 个股全部大涨,但是系统没有给出落袋为安的建议,今天跌下来了却让我卖出。系统应该综合量化与信息综合判断,下跌的股会不会涨回去,如果能涨回去就不要卖掉。反过来,股票上涨时应该准确判断何时该卖掉变现,哪怕第二天还有涨的趋势再买回来也行。在何时卖掉这个问题上还得深度调研,设计完美的机制。量化指标不会骗人,平台一定要足够重视量化指标,其他的都是辅助判断的锦上添花。」
> **方法**:① 生产实证复盘(logs + manifests + broker 镜像逐笔还原 06-03/06-04);② 双路深度调研(国际退出机制文献 + A 股特化实证);③ 红线内机制设计 + 分期实施计划。
> **前置结论**:owner 观察到的「涨时不卖」主因是一个**生产数据 bug(已修,`7c69fa4`)**;但「何时卖」的策略层确有 **3 个真实缺口 + 3 个次生 ops 缺口**,本文逐一设计修法。

## 2. 调研结论 I:国际退出机制(要点 + 参数)

> 完整出处见 §7 sources。仅列与设计直接相关者。

### 2.1 Chandelier exit 正典锚定(LeBeau 原文)——证实 G1 是「非标准实现」

- LeBeau 原版:*"Place a stop at the highest high **since we entered the trade** minus three Average True Ranges."* 锚 = **入场以来最高价**,单调棘轮上移;绝不是固定回看窗口。我们继承的是 StockCharts/TradingView 的 22-bar 简化版(社区甚至专门有 "Anchored Chandelier Exit" 指标来恢复 since-entry 语义)。
- LeBeau 分层结构:**新仓位另设独立的初始资金管理止损(money-management stop)**;chandelier 只在棘轮上移**超过**初始止损后才接管。止损线贴在成本附近假装「保护利润」正是缺少这一层的症状。
- 乘数:LeBeau 开仓阶段 **2.5–4×ATR**(示例 3×);Elder/StockCharts/Clenow 默认 3×;Van Tharp 2.7–3.4×(10 日 ATR)。**我们的 2× 处于 whipsaw 高发端**。LeBeau 自适应通道:开仓宽(3-4×)、盈利累积后**才**收紧(2-2.5×)——方向与「越涨越紧」一致,与「一开始就紧」相反。
- 锚定用最高**收盘**而非最高价、并以收盘触发,是公认的降 whipsaw 变体(代价:真破位出场更晚)。

### 2.2 Whipsaw 滤波:确认机制的标准修法

- **收盘确认 vs 盘中触碰**:文献明确——盘中触碰是 whipsaw 主源,收盘(或末段时段)确认是标准修法;代价是真破位滑点变大(用深度分层对冲,见下)。
- **深度分层(two-stage / triple-barrier)**:深破(如破位 > 0.5×ATR 或跳空穿越)→ 立即出;浅破 → 收盘/双 bar 确认。Van Tharp 双止损(宽 3× trailing + 紧 2× 单日逆动)同构。López de Prado triple-barrier(止盈/止损/时间三栅栏)是干净的形式化框架。
- **量能确认**:有效破位伴随 ≥1.5× 均量;缩量破位大概率假摔。
- 大样本回测佐证(KJ Trading 567k 回测 / 87-stop 研究):trailing 显著优于静态止损;**1×ATR 级别的紧止损严重跑输**;最优紧度依赖 regime → 印证我们 D1-b/c 的 regime 条件化路线。

### 2.3 A 股微观结构:为什么早盘触发的止损系统性卖在最差时点

- **T+1 制度性隔夜负收益**:卖方被迫集中在次日开盘 → 开盘买方议价力 60.03% vs 卖方 39.97%,隔夜折价年化 ≈ **−11.9%**(朱红兵&张兵 2020,深交所)。
- 日内结构「先抑后扬」:早盘弱、**尾盘 15-30 分钟收益最强**;上半小时收益预测全天。→ **早盘触碰即卖 = 把单子交在结构性最弱时点**;600011/600909 的 06-03 案例是教科书级别。
- A 股**短期反转效应强、动量效应近乎缺席**(2008 后动量消失,反转主导;高波动 regime 反转更强)→ 趋势型 trailing stop 在 A 股的 whipsaw 比美股/期货更严重,更需要收盘确认 + 宽乘数 + regime 条件化。

### 2.4 时间止损与再入场(补全退出栈)

- **时间止损(vertical barrier)**:动量 swing 的 edge 約 8-15 交易日耗尽;N 日无进展(如 10 日内 < +3-5%、无更高高点)→ 出清释放槽位。与我们 ≤5 槽轮动天然互补(占槽的「僵尸仓」正是轮动想解决的)。
- **再入场(Turtle fail-safe)**:止损后**仅在趋势重新确立时**买回(突破 20 日高仅当上次同信号是亏损时;否则要求更强的 55 日突破)——防止「刚被洗出去又追回去」再挨一刀。盈利了结后的回补:余仓骑 trailing,加回仓位要求新突破或回踩均线确认。

## 3. 调研结论 II:A 股「强势卖出」特化(要点 + 参数)

### 3.1 关键横切结论:卖强的「时间维度」必须分清

- **当日封死涨停 → 次日继续上涨概率 79.4%**(Wan et al. 2015,全 A 2000-2011,40,752 样本)+ 隔夜负折价 → **封死的涨停不在次日开盘卖**(双重亏:错过延续 + 卖在折价点)。
- **多日急涨/盘中过强 → 未来 ~20 日反转主导**(民生金工 2025「动量脉冲」因子;多篇反转文献)→ 抛物线式连涨是**实证支持的卖强对象**。
- **再买回的最优时点 = 次日开盘**(隔夜负折价对买方有利);**卖出的最优时段 = 日内拉升中**(日内收益偏反转),避开开盘。→ owner 的「卖了第二天买回来」方向与微观结构完全相容,且有明确的最优执行时段。

### 3.2 确定性强势卖出信号族(全部可由 spot 行 + 日线历史复算,零 LLM)

| 信号 | 确定性判据 | 实证锚点 |
|---|---|---|
| **炸板**(触涨停后回落) | day_high = 涨停价 AND 现价 ≤ 涨停价×(1−2%) | 炸板次日溢价为负(多源一致);封死≠触板 |
| **放量滞涨/天量高换手** | 成交额 ≥3× 近5日均额 AND 日内涨幅 < +3% AND 价位在 MA20 上方 ≥10% | 「高位离场5信号」之天量避雷针/天量高换手;华安:放量首板次日 −0.71% vs 缩量首板 +7.44%/91.7% 胜率 → **量是强势卖出的第一判别器** |
| **冲高回落** | 日内最高涨幅 ≥ +6%(vs 昨收)AND 从日内高点回落 ≥3% | 民生金工「偏锋涨跌幅」20 日反转;practitioner 带 3-5% |
| **乖离率超买** | BIAS₂₀ = (price−MA20)/MA20 ≥ 个股分位校准阈值(默认 +15%,D1-a 同法) | 经典阈值 6/12/24 日 +8/+15/+30%;高β股放宽 → 正好复用 D1-a 校准框架 |
| **封死涨停反向豁免** | 现价 = 涨停价(封死)→ 当 tick 抑制全部止盈/卖强触发 | 79.4% 次日延续;「让利润奔跑」的确定性版本 |

### 3.3 分批与梯子

- ATR 梯子共识(+1R 卖 1/3,+2R 再 1/3,余 1/3 骑 trailing)与我们 D1-d 已建的 (1.0,2.0)×eff_r 阶梯一致 ✅。
- 信号耦合减仓:**每出现一个顶部信号减 1/3,≥2 个信号高概率离场**(新浪高位离场框架)→ E3 采用「每信号一档」而非全清。
- 华安阶段自适应止损(情绪高潮 −5%/衰退 −3%/冰点 −2%)→ 印证 D1-b regime 条件化方向。

## 5. 机制设计:卖出栈 v2(全部确定性、零 LLM、单一构造点不变)

> 共同约束:全部触发仍走 `evaluate_intraday_sell_intents` → `assemble_monitoring_plan`(单一构造点)→ 5 早返 → RiskEngine 14-check → 飞书人工 gate。新参数全部 frozen dataclass 运行期不可改,入 config_hash(PIT 复算);每模块独立 env gate 默认 OFF + 各自 amendment。**信息面(新闻/LLM)不进任何阈值或方向**——owner 的「锦上添花」由既有 W 路径盘后 advisory(display-only)承载。

### E1 锚定修复:since-entry chandelier + 独立初始止损(修 G1,最高置信度)

```
entry_date   = 持仓建立日(takeprofit_ledger episode / bought_by_date 派生,确定性)
anchor       = max(daily_close[entry_date..T-1] ∪ {当日盘中已见最高价*})   # 入场以来最高
initial_stop = cost − 2.0×ATR                                              # 资金管理止损
chandelier   = anchor − 3.0×ATR                                            # 乘数 2→3(LeBeau 正典带)
stop_level   = max(initial_stop, chandelier)                               # 棘轮:chandelier 高于初始止损后接管
```
\* 当日盘中高点取自 spot 行 `high` 字段(PIT:落 manifest 的就是消费的那行)。
- **对 06-03 的反事实**:600909 stop 6.75(非 7.24)→ 7.10 不触发,免于卖在 +6% 反转日低点 ✅;600011 stop 8.62(非 9.17)→ 8.72 不触发 ✅(若继续跌破 8.62 = −6.4% 再出,职责清晰是止损);605020 大涨后 anchor 升至 36.36,3× 下今日不出、2.5× 下今日收盘出——乘数即「让利奔跑 vs 锁盈」旋钮,默认 3.0,经 D1 校准框架可个股化。
- 止损语义随之诚实化:跌破 initial_stop 的飞书消息措辞是「止损」,跌破 chandelier 的是「回撤锁盈」——owner 不再把止损误读为止盈失灵。

### E2 触发确认:深度分层 + 收盘确认窗(修 G2)

```
深破(立即出,本 tick 路由):price ≤ stop_level − 0.5×ATR,或 DRAWDOWN_STOP(−5% vs 昨收,保持现状)
浅破(确认后出):stop_level − 0.5×ATR < price < stop_level
    → 不立即路由;仅在「确认窗」14:30–14:55 内仍 < stop_level 才路由
```
- 直接利用 A 股「先抑后扬+尾盘最强」结构:早盘浅破不卖,尾盘确认仍破才卖(在当日最强时段出手,还顺带规避次日开盘隔夜折价)。
- 灾难保护不弱化:−5% 盘中崩跌与深破仍即时;只有「浅破」获得日内复原机会。600011 06-03 案例(8.72,浅破 9.17 旧线;新线 8.62 下根本不触发)双保险。

### E3 强势卖出触发族(修 G3;§3.2 的工程化)

新增 `IntradayTriggerKind` 四种,优先级插在 DRAWDOWN_STOP 之后、TAKE_PROFIT 之前;每信号独立 (code,kind) 日去重;减仓量 = 1/3 当前已结算(按手取整,clamp ¥50k),与 D1-d 阶梯共用 episode 账本语义(各档 delivered 才推进):

| kind | 判据(全部来自 spot 行 + 日线帧) | 减仓 |
|---|---|---|
| `LIMIT_BREAK`(炸板) | day_high ≥ 涨停价−0.01 AND price ≤ 涨停价×0.98 | 1/3 |
| `SURGE_FADE`(冲高回落) | (day_high/prev_close−1) ≥ +6% AND (price/day_high−1) ≤ −3% | 1/3 |
| `VOLUME_CLIMAX`(放量滞涨) | 当日成交额 ≥3× 近5日均额 AND 日内涨幅 < +3% AND price ≥ MA20×1.10 | 1/3 |
| `OVERBOUGHT_BIAS`(乖离超买) | (price−MA20)/MA20 ≥ 阈值(默认 +15%;D1-a 同法个股分位校准) | 1/3 |

### E5 再入场规则(修 G4 后半;owner「第二天买回来」诉求)

```

  → RE_ENTRY(BUY)建议,量 = 昨日卖出量(clamp 预算/15% 单股上限),经 Line-2 ADD 同管道(单一构造点)
```
