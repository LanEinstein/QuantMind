## 二、总体仓位行为框架（handoff 第一部分）

### Q1 五个词只作行为语言？

**建议：接受，但把定性从「研究分类」升级为「作者原词表」。**

**直接证据**

- `7653441144290394752 / s6-17`（2026-06-21）：
  「那很多小伙伴啊听到我的建议啊，那这一周开仓之后呢，你肯定是做到了一个套利啊，所以说你你们要去了解空仓、试错、加仓、退仓、锁仓啊，这几句话的含义啊。那在这一周啊，我们是目前为止是没有看到确定性的那你就要保持原有的试错，仓位啊不要变啊，」
  ——**五个词由作者一次说全**，且顺序与草案一致（「退仓」即「推仓」，见 Q3）。同句还给出了状态维持条件：**没有确定性 → 试错仓位不变**。
- `7631897916105586147 / s73-78`（2026-04-23）：
  「狼也冲这样子对吧所以说空仓嗯加。仓推仓锁仓跟，情绪周期实际上是个完。整的，周期啊记住没有我是真教呀啊再给你们看，看我？」
  ——四词版本，并**明确绑定情绪周期**（该视频主题即退潮期为何不能做）。同条自述（`s63-70`）「现在很小很小也就是说退潮期，的时候哎我基本上不玩，啊就是或者说就玩一点点，无所谓的能能理解吧根本不，影，响我呃账户的回，撤的这就是怎么控制回撤等到出现机会的时候，就跟上一次那个二版的时候推进去账户一下子曲线就这。」。
- `7674972282468721064 / 767497-lock-after-feedback`、`7673825445741718117 / 767382-three-expectation-branches` 等新增 23 条，是同一套词在 8 月的重复使用。

**反证与歧义**

1. **不是互斥状态机**。同一时点可以「大金融锁仓 + 短线试错 + 另一账户不可见」。1104（`767527-account-boundary`）明说「我的另外另外一个账户。我一般不怎么截图给你们看知道吧这个这个账户完全是，为你们？开的只是我的一个小账户而已」。任何把五词写成单一状态变量的实现都会伪造出语料没有的排他性。
2. **「试错」有两种用法**：一是情绪周期阶段词（`7565135321076763938`「现在你要学情绪。周期了冰点试错主身震荡，退潮高潮」，「主身」为 ASR）；二是仓位状态（上引「保持原有的试错，仓位啊不要变啊」）。两种都真实，但**结算口径不同**，不能混。
3. **两个版本词数不同**（四词 vs 五词），说明词表本身也不是他严格维护的枚举。
4. 所有词的**进入/退出阈值全部没有**。

**对系统的影响**

- 冻结：五个词作为 Base 的行为词表（连同「这是作者原话」这一事实）、以及它们之间的动作关系（空仓/试错→确定性→加仓/推仓→符合预期锁仓→不符合预期退出）。
- 明确不冻结：任何阈值、比例、账户分母、词与词之间的排他性、转移函数。
- 下一阶段验证：五词能否用「当时可见」的观察量区分（尤其「确定性」与「符合预期」）。在此之前，它只是登记语言，不是可执行状态。

**给 owner 的话**：这一项可以放心确认。它比草案写得还稳一点——不是我们给他的行为起名字，是他自己列的清单，我们只是把清单抄下来并注明「含义未冻结」。

### Q2 「锁仓」是否拆分？

**建议：接受拆分，但拆三类（不是两类），并把第四种含义逐出仓位框架。**

**直接证据**

- **① 规则内主动持有**：`7673825445741718117 / 767382-three-expectation-branches`（8/14）「符合预期，锁仓不符合预期，跑超预期加仓。啊，那今天既然符合预期，那我就锁仓。」
  配套 `7630717529065111267 / s1-12`（2026-04-20）：「就是说当你带上了交易系统，你就择了锁仓，就不要害怕第二天吃地板或者是止负反馈，因为这是你认知以类的。」——**主动锁仓是一个事前带止盈止损的选择分支**。
- **② 被迫锁仓（套住、动不了）**：`7672299620257681570 / s14-25`（2026-08-10）：
  「是因为大科技的这一部分筹码被迫锁仓了啊。嗯，不是说他为什么他他为什么锁仓了，他不是不是不是，他不想去呃锁仓那个呃出来啊，是因为他被套多了啊，他动不了，所以说他只能被迫在里面躺平啊」
  ——**「被迫锁仓」四个字是作者原词**。这条讲的是市场浮筹不是他自己的账户，但**词义分层是他建立的**，不是研究者外加的。
- **③ 承诺/执念驱动的持有**（本轮新增证据最集中的一类）：
  - 1089 `767334-lock-commitment`：「因为我话已经说出去了……我说我要锁藏两天不摸四千点，我不走。那我今天走了，我不是背信弃义吗？所以我思考了再三，我还是选择格局」——当天他其实**想走**（「我也想走，我怕冲高回落」），不走的理由是**公开承诺**。
  - 1099 `767489-lock-and-full-attack`：压力来源被明说成粉丝信任与声誉（「我损失的是信誉和内疚」）。
  - 1106 `767556-4000-obsession`：「我是有执念的，就是说我非要摸到四千点之后我才跑」。
  - 1108 `767561-trigger-apology`：「我不该说锁仓得摸四千点啊」。
- **④ 主力锁仓 / 筹码锁仓**（叙事层）：`7581413632690539776`（2025-12-08，「是因为温和放量的话，是证明主力锁仓散户在卖啊」）、`7611446498963244495`、`7626700051746734178`（「被动锁仓」用于形容资金）。这是 X1 不可识别主体叙事，**必须与仓位框架完全分离**，否则「锁仓」会同时既是我方动作又是对手方推测。

**反证与歧义**

- 三类在**动作外观上完全相同**（都表现为「不动」），只有驱动来源不同；而驱动来源只能从口播识别，无回单。所以拆分只能拆在**研究登记层**，不能拆成执行层的两个状态。
- 「被套」是盈亏状态，不是决策类型：8/13 他是**主动决定**继续持有的（有承诺这个非市场理由），当时还是浮盈（「如愿挣到六位数」）。如果按 owner 问题里的「因亏损/犹豫而被迫套住」来命名，8/13 会被错分。因此本稿建议按**驱动来源**分，而不是按盈亏分。

**建议的三分命名**（仅为讨论用词，owner 可改）

| 名称 | 判据 | 本轮样本 |
|---|---|---|
| 锁仓（规则内） | 事前分支成立（符合预期），且事前已有退出条件 | 8/14 1094 |
| 滞留（被迫） | 想动而动不了/无退出条件；含被套躺平 | 作者用于形容市场筹码（2026-08-10）；他本人账户无回单，本轮不可判定 |
| 承诺锁仓（声誉/执念驱动） | 持有理由是对外承诺或点位执念，而非模式反馈 | 8/13 1089、8/17 1099、8/19 1106/1108 |
| （主力锁仓） | 对手方叙事 | 逐出框架，归 X1 |

**对系统的影响**

- 冻结：「锁仓」是多义词，登记时必须带驱动来源标签；不带来源的「锁仓」不得进入任何统计母集。
- 明确不冻结：三类的自动判别方法（只能人工按口播打标）。
- 下一阶段验证：M3 做任何「他的系统是否被执行」的评估时，**承诺锁仓必须单独成组**，否则 8/13—8/19 这一整段会被误算成「系统正常运行」。

**给 owner 的话**：这条拆分是本轮最有价值的一项，理由很直白——8 月 13 日到 19 日这段，**规则说该走、他没走、原因是他对粉丝有言在先**。如果不拆，复刻出来的系统会把「因为面子不走」学成「因为符合预期不走」，这是两件完全相反的事。

### Q3 「推仓」只保留为风险极值/反例？

**建议：修改后接受——不同意「只作反例」，但同意「不作无条件鼓励」。应把「推仓」与「全军出击」拆成两件事。**

**直接证据（推仓是他系统里有定义的正向动作）**

- `7557726475514334504 / s15-26`（2025-10-05）：「嗯，你就可以做出盈亏比，就是可以退仓位了。什么是退仓位？就是比如说你每次开仓，比如说是一成仓、两成仓，三成仓，那你的成功率都比较高。」——**作者自己给「退仓位」下定义**：相对于常规开仓量的加权。
- `7531632564613369128 / s44-55`（2025-07-27）：「比如像，野哥？我是不敢退仓位的但是大盘占上三千五了对吧我？肯定会退仓位的仓位加一个仓位加重了」——**同句自我改写为「仓位加重」**，这一条单独就足以消歧。
- `7628182050198527395 / s9-20`（2026-04-13）：「你，用小资金去试水温到确定性买点的时候你，的确定性买点时候你，去敢于推仓位啊这，就是我跟你们说的盈亏比」——推仓的前提是**模式内确定性买点**，路径是**小仓试水→确定性→加权**。
- `7566965615812031714 / 756696-s53-64`（2025-10-30）：放量大阳线穿两三根阴线「这个是一个野鸽的推仓位的确定性干干点啊」——证券层的推仓触发形态。
- `7552015322325699840 / 755201-s2-16`（2025-09-20）：「只有到你的确定性机会出现的时候，才可以退仓位啊，这就是做盈亏比的来源啊」，同句还禁止**浮盈加仓**。

因此：**1097 的「超预期退仓位」在语料级可以消歧**，它与 1094/1098 的「超预期加仓」是同一动作方向。草案要求逐条保留 ASR 原词是对的，但可以在 ontology 里登记一次词条，不必在每张卡上重复声明「不可消歧」。（`H-POSITION-CONVICTION-001-R6` 其实已经把「推仓位」当作提高暴露在用了。）

**直接证据（全军出击是另一回事）**

- `7673060086088417699 / s3-14`（8/12 晚）：「他三三天已经加了一万手多单，明天不会买我吧。我靠，刚刚的我刚全军出击，他就干我嘛。……但是我野哥依然相信他是纯做多啊。」
  ——**「全军出击」的公开理由是「信爷/机构加多单」，即 X1 不可识别主体叙事**，不是模式内确定性买点。这正是 Base §2.8 X1 标注的最高风险形态（叙事-动作绑定）。
- 1099 `767489-lock-and-full-attack`：全军出击与「锁仓不到四千点不减」被并列为「两句话」，压力来源是粉丝信任。
- 同一条 `767489-strong-repair-exit` 又要求「依然要保持半仓」防踏空——**同日同条内就出现了口径漂移**。

**反证与歧义**

- 我**没有**用「后来亏了所以推仓是错的」来论证——那是收益择优，Base 明令禁止。论证依据是**结构**：推仓在语料里有前提（确定性）、有配套（盈亏比）、有禁例（不许浮盈加、不许下跌补）；「全军出击」这一次的前提是不可核验叙事，且没有任何撤回条件，不满足 B1（提高暴露必须事前定义失败撤回）。
- 反方向的诚实披露：作者从未说过「全军出击是错的」；1109 减到三成时给的理由是「风险大于机会」，不是「全军出击不该做」。所以把「全军出击」定成反例是**我们的分类**，不是他的自述。

**对系统的影响**

- 建议冻结：`推仓 = 模式内确定性出现时相对常规开仓量的加权`（无数值），且**必须绑定 B1 撤回条件**才允许进入目标系统的正向语义；`全军出击 = 叙事/承诺驱动的仓位极值`，登记为反例与风险样本。
- 明确不冻结：常规开仓量、加权幅度、「确定性」的可观察定义。
- 下一阶段验证：能否用当时可见量给「确定性买点」一个可结算定义。在此之前推仓**无法执行**，但它应该留在 Base 里，否则复刻出来的系统缺了他最强调的「盈亏比」。

**给 owner 的话**：如果照草案原案把「推仓」整体降级成反例，我们复刻出来的会是一个**只会小仓试错、永远不会重仓**的系统——那不是他的系统。他的系统是「平时很小、看到确定性就敢压」。真正该当反例登记的是 8 月 12 日那次：**理由是期指多单叙事、而且没有留退路**。建议把这两件事分开确认。

**owner 问的「四层分开」，建议做成五层**（多出「触发是否成立」这一层，因为它与「是否执行」是两件事）：

| 层 | 字段含义 | 8/12—8/19 案的取值 | 可核验性 |
|---|---|---|---|
| L1 事前规则 | 动作前公开绑定的时间窗×条件 | 锁仓两天；周四五不摸 4000 则减仓 | ✅ 原话可核 |
| L2 触发是否成立 | 按规则口径判定 | 按作者口径成立（8/12 周三定规则，8/13 周四、8/14 周五均未摸 4000；他本人 8/19 承认未按原口径离场） | ⚠️ 点位需指数 PIT 复核，本轮未做 |
| L3 作者声称的动作 | 他说他做了什么 | 8/13—8/18 称继续持有；8/19 称减到三成 | ✅ 口播可核 |
| L4 是否按 L1 执行 | 规则与声称的一致性 | **不一致**，且作者自认（1106）并撤回（1108） | ✅ 口播可核 |
| L5 真实成交回单 | 账户、证券、数量、成交价 | **永久缺失** | ❌ |

**反证与歧义**

- 不能升级为「锁仓规则无效」：失败发生在 L4（执行），不在 L1（结构）。失败的原因在 Q2 里已定性为「承诺/执念驱动」，属于人的因素。
- 也不能假装成功：Base v2 D7 已改写为：触发器结构保留，执行语义改为「已有未按时执行并撤回原口径的口头反例，实际成交仍未知」。这一改写准确，建议保留。
- L2 目前无法机器判定：Base §五未冻结参数表已列一行：指数点位序列（4000 点门禁的触发判定），状态为「PIT 未归档指数日线」。这是 M3 的一个具体待补项（注意：执行计划 §2.2 显示 `index_daily_major` 已覆盖上证综指等到 20260819，L2 很可能已经可判定，建议 M3 开工时先复核这条缺口是否已经消失）。

**一条建议增补的样本**：1109 `767564-tech-exit-and-themes`「是大科技千万不要走出下跌，中继的形态一，旦走出下跌中继形态啊，你不管亏多少都要清仓不然的话你会亏的」——这是同族的**形态型事前触发器**，比 4000 点更接近可操作，建议与 4000 点并列登记为样本。

**对系统的影响**：冻结「入场/加仓前绑定唯一反馈窗口与退出条件」的结构语义与五层分账要求；不冻结 4000、两天、指数对象、减仓幅度。下一阶段验证：L2 的可判定性；以及「事前有触发器」与「事后有解释」在语料里的比例（这是复刻质量的关键指标，不是命中率统计）。

**给 owner 的话**：这张卡是整套系统里最像「系统」的一条，建议确认。但请把「他说了规则」「规则触发了」「他说他做了」「他其实没做」「有没有回单」当成五个独立字段——8 月这一案里，前三个是有的，第四个是失败的，第五个永远没有。以后任何评估都不能拿第三个冒充第五个。

### 卡 6：混沌—退潮—恐慌盘防守链 —— 建议「接受」

**直接证据**

- `7517573542352129332 / 751757-s2-22`（2025-06-19）：「我前天说了，这是个混沌期，它混沌期它就它就会杀透，如杀透。没有恐慌盘出来，他是不会止跌的，知道吧？所以一个管住手，第二个控制好仓位。」
- 1092 `767372-short-term-retreat-warning`（8/14）：「短线开始出现情绪突退潮的迹象啊，要注意仓位管理啊」——**限定在短线/超短/情绪票**。
- 1106 `767556-repair-reduce-retreat`（8/19）：「今天野哥的短线啊，就比手速了已，经退潮了对吧那卖飞就卖飞了后面涨跌与我，无关」。
- 1109 `767564-finance-and-capital-risk`：「在这个阶段机会啊风险大于机，会量所以说啊规避风险那就是控制仓位啊」。
- 组合层的行为样本：`7631897916105586147 / s63-70`（2026-04-23）「现在很小很小也就是说退潮期，的时候哎我基本上不玩，啊……根本不，影，响我呃账户的回，撤的这就是怎么控制回撤」——**退潮期＝压缩暴露、控制回撤**，这正是这张卡的组合层职责。

**与卡 2 的职责分离：接受，理由见卡 2**（1092 单条内并列 + 两卡作用对象不同：卡 2 选强，卡 6 降总暴露）。

**反证与歧义**

- 「没有恐慌盘不会止跌」**不能反推**「出现恐慌盘就可以抄底」。恐慌盘无观测量。
- 退潮不等于清仓：`H-MARKET-CHAOS-RETREAT-001-R5` 已写明「关闭追逐轮动的新入口，但机构主导、硬逻辑且趋势未失效的波段仓可以持有」；1092 的大金融并列是直接证据。
- 一次局部回流不结束退潮（同 R5）。

**对系统的影响**：冻结「风险占优→先关闭追逐型新入口→分层缩减暴露→等待情绪拐点→只允许有限试探」的链条与 B5 分层风险预算；不冻结退潮/恐慌盘/修复的观测阈值、试探规模、波段仓保留条件。下一阶段验证：退潮的可观察代理（涨停数、连板高度、赚钱效应）能否与他的口播时点对齐——注意这是**语义对齐**，不是命中率统计。

## 五、建议 owner 额外裁决的四个新增项（handoff 未列）

### 1. 系统版本漂移政策（最重要）

语料横跨 2025-06 至 2026-08，作者的系统本身在变：

| 例 | 旧口径 | 新口径 |
|---|---|---|
| 补仓 | 2025-10-30：浮亏 5—8 点 + 反转信号可**主动补仓**；-15% 止损 | 2026-08-17/18：下跌不能补，只有超预期才加 |
| 入场措辞 | 2025-07—09：红肥绿瘦（3 次） | 2026：0 次 |
| 角色轮换 | 2025：分歧切核心 / 弱势抱团 | 2026：去弱留强（同题材内） |

**建议**：Base 复刻以**最新版本为准**，旧版本用 Base §四已有但当前为空的 `phase_rule` 分类归档（注明起止时间与被取代关系），**不删除、不合并、不用新版覆盖旧版的原文**。
**需要 owner 拍板的是**：复刻目标是「他现在的系统」还是「他讲过的全部方法的并集」。前者更可执行，后者更完整但内部会自相矛盾（补仓这一条就直接冲突）。

### 2. 「推仓位/退仓位」的词条级消歧

建议在 ontology 里登记一次：`推仓位 = 退仓位 = 相对常规开仓量提高暴露`，依据 `7531632564613369128 / s44-55`（同句自我改写为「仓位加重」）、`7557726475514334504 / s15-26`（自带定义）。
登记后，各卡片不必再逐条声明「ASR 不可消歧」——**幅度**仍然未冻结，但**方向**已经确定。这能省掉后续大量重复的免责声明（也符合反过度防御：重复声明一个已被证据解决的问题，不改变任何决定）。

### 3. 把「仓位性质」作为卡片编排的第一分叉

Base P4 已经冻结了「套利仓／波段仓分立登记」。本轮证据显示这条分叉**贯穿全部六张卡**：

| 分支 | 卡片 | 特征 |
|---|---|---|
| 波段仓 | 卡 1 右侧波段 → 卡 4 禁补仓 → 卡 5 事前退出触发器 | 可重仓、锁仓/格局、持有一至三个月 |
| 套利仓 | 卡 2 去弱留强 → 卡 3 红卖绿买 →（候选）520 | 不谈格局、反馈窗口以天计、挣一口就走 |
| 组合层 | 卡 6 防守链 | 管总暴露，跨两支 |

**建议**：卡片编号保留，但在卡面第 2 项「适用市况」之前先标注仓位性质。这样「格局 vs 红卖绿买」「锁仓 vs 挣一口就跑」这类表面矛盾在结构上自动消解。

### 4. 「极致性价比」其实有一条口径

草案与 Casebook 都写「极致性价比未冻结」。但 `7671135038796520360 / 520360-s15-20`（2026-08-07）给了口径：
「什么是极致下性价比？就是我以前做过两次那种强反弹对吧？那很很很准的这种节奏，就是你**日内的浮盈能达到十个点以上**。」
同条 `520360-s21-41` 还给了反面：日内只有两三个点的浮盈没有意义，且「大概率你是会被闷的」。

**建议**：从「完全未冻结」改为「**有作者口径，待验证**」——它是一个可观察量（日内浮盈幅度），只是没有母集也没有回单。这条同时约束了 1106 的「极致性价比强反弹」：它不是无条件的抄底许可，作者原话的门槛相当高，且他明确说「所以啊呃为什么强。反弹不能做」「包，括强反弹啊不要轻易的去做模式以外的，东西啊啊」。
