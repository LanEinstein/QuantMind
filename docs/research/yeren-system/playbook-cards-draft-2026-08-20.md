## 总体仓位语言：空仓 → 试错 → 加仓 → 锁仓 → 推仓（待 owner 确认）

五个词是作者的行为语言和研究分类，不是系统中的枚举、转移函数或下单动作。相同词在不同账户、周期和修辞上下文中可能含义不同；没有分母、证券、数量和回单时，只记录作者声称。

### 空仓

1. **博主原词及上下文含义**：空仓至少有模式失效空仓、风险占优时暂停新仓、现金为主、卖清可卖仓和 T+1 残仓五种不能混合的语境。退潮首先关闭追逐新入口，不自动等于所有持仓清零。
2. **进入前提**：模式失效，或市场/组合风险占优且没有满足试错条件；“看不懂”可作为作者语言，但不是统一清仓阈值。
3. **允许动作**：保留现金、等待下一反馈窗口；在风险占优但证券逻辑未失效时，保留已持有的强势/机构主导波段仓，或只做有限试探。
4. **禁止动作**：把短线退潮、单次盘中下跌或“没有恐慌盘”机械翻译成全账户清仓；不能把 T+1 残仓当成现金。
5. **离开或转入下一状态的证据**：出现情绪拐点、可交易分歧或明确修复，才可能进入试错；一次局部回流不代表退潮结束。
6. **反例、漂移和口径冲突**：1092 将短线退潮与大金融低波动防守并列；1106 说短线已退潮但修复时可减一点，显示组合层和题材层不同步。
7. **原话 span 与出处**：旧证据 `751757-s2-22`（7517573542352129332）：“没有恐慌盘出来，他是不会止跌的……管住手……控制好仓位……撤退。”这只支持防守语言，不支持固定清仓。

### 试错

1. **博主原词及上下文含义**：试错是退潮或清仓后，在情绪拐点/有限修复中用小暴露重新观察，不是按固定天数自动重入。
2. **进入前提**：出现可交易修复、极致性价比或首次可交易分歧；证券/题材身份和失败窗口仍需当时可见。
3. **允许动作**：少量试探，预设下一反馈窗口；1106 的“极致性价比强反弹”只提供方向性样本。
4. **禁止动作**：把“跌得多”本身当成抄底信号；把被套摊低成本写成试错；用固定百分比或天数伪造轻仓。
5. **离开或转入下一状态的证据**：修复符合预期可继续观察或进入加仓候选；修复失败回到空仓/防守，不因原有浮亏继续加。
6. **反例、漂移和口径冲突**：1106 说科技极致性价比可做强反弹，但没有阈值；1093 的指数修复预期也明确“消费到什么程度不知道”。
7. **原话 span 与出处**：`767556-rebound-and-reduce`（7675567648260797327）：“如果说出现极致性价比的时候啊，我们是可以去做一个强反弹的……”——`极致性价比`未冻结。

### 加仓

1. **博主原词及上下文含义**：加仓是对超预期、计划内支撑回踩或原逻辑增强的新增暴露，不是下跌后的临时摊低。
2. **进入前提**：原逻辑未失效，反馈达到作者称为“超预期”的分支，且新增部分有单独失败撤回条件。
3. **允许动作**：在事前支撑小回调且趋势未失效时分批增加；超预期才允许新增暴露；新增部分与原仓分开记录。
4. **禁止动作**：下跌/补跌时补仓；把“看多”或利润垫直接当加仓充分条件；用不同账户替作者消歧。
5. **离开或转入下一状态的证据**：新增暴露反馈失败时撤回新增风险；继续符合预期才可持有，不能把失败回写成锁仓。
6. **反例、漂移和口径冲突**：1097 的 transcript 原词为“超预期退仓位”，可能是“推仓位”，不能擅自修成加仓；1099 的全军出击与后续半仓显示数量口径漂移。
7. **原话 span 与出处**：`767485-no-loss-averaging`（7674853745528435427）：“跌的时候……不能补的，只有超预期的时候才能是加。”证据支持动作方向，不提供数值。

### 锁仓

1. **博主原词及上下文含义**：锁仓有主动按预期持有、被迫躺平、流动性叙事和时间窗退出四种可能，不能先验合并成正面状态。
2. **进入前提**：符合预期，或作者事前公开绑定了时间窗×点位触发器；“锁仓”本身不能证明账户实际没有卖出。
3. **允许动作**：符合预期时拿着不动，等待唯一反馈窗口；触发器成立后按预设减仓；不同账户/交易类型分别记录。
4. **禁止动作**：因为已经说过“锁仓”就把新信息压掉；把锁仓承诺当成功执行；把不符合预期时的拖延解释成长期 conviction。
5. **离开或转入下一状态的证据**：触发窗口到期、点位未达、反馈失败或作者明确减仓；真正执行仍要订单/回单，口头计划不够。
6. **反例、漂移和口径冲突**：1089、1091 先声称继续锁仓；1106 又承认执着于 4000 点、3994 点未按原口径离场，说明触发器可以结构明确但执行失败。
7. **原话 span 与出处**：`767334-lock-commitment`（7673340862160764131）：“我说我要锁藏两天不摸四千点，我不走……不看到四千点也割不走。”这是口头持有证词，不是回单。

### 推仓

1. **博主原词及上下文含义**：推仓/全军出击是仓位极值或作者的进攻叙事；1097 的“退仓位”原词未消歧。它可以作为反例和风险极值研究，不能当目标系统正向状态。
2. **进入前提**：作者自述的超预期、强修复、利润垫或“冲击4000点”叙事；这些前提都未冻结，也没有统一分母。
3. **允许动作**：在研究记录中保留“新增暴露/极值”事实和失败反馈；目标系统层面当前不把它转成推荐动作。
4. **禁止动作**：把全军出击、满仓、三至五成→八成→半仓写成跨期比例；把利润垫或主力叙事当风险豁免。
5. **离开或转入下一状态的证据**：强修复不满足同步发力、退潮或作者自述触发失败时进入减仓/防守；实际状态仍须回单。
6. **反例、漂移和口径冲突**：1099 同时出现全军出击、4000 触发高抛低吸和保留半仓；1106 是“执念导致未及时离场”的执行反例。推仓不构成闭环。
7. **原话 span 与出处**：`767489-strong-repair-exit`（7674890673190899520）：“摸四千点……没有大金融和大科技同时发力上攻……高抛低吸……依然要保持半仓。”这正是比例未冻结的证据。

4. **加减仓与退出规则**：不追高；新增暴露失败时撤回新增部分；不符合预期或趋势失效时退出。亏损后临时补仓不属于本卡。
