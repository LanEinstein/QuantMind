## 一、总体仓位行为框架（确认稿）

### 裁定 1：五个词＝作者原词表，作行为语言，不建状态机 ✅ 接受

**定性升级**：草案写「研究语言／研究分类」，实为**作者自己的枚举**。

- `7653441144290394752 / 394752-s0-19`（2026-06-21）：「那很多小伙伴啊听到我的建议啊，那这一周开仓之后呢，你肯定是做到了一个套利啊，所以说你你们要去了解空仓、试错、加仓、退仓、锁仓啊，这几句话的含义啊。那在这一周啊，我们是目前为止是没有看到确定性的那你就要保持原有的试错，仓位啊不要变啊，」
- `7628182050198527395`（2026-04-13）作品标题即：「4月13日闲聊盈亏比，空仓，试错，锁仓。加仓。这几个字你们一生受用」。
- `7631897916105586147 / 586147-s50-77`（2026-04-23）：四词版本「所以说空仓嗯加。仓推仓锁仓跟，情绪周期实际上是个完。整的，周期啊」。

**冻结**：词表本身 + 词与词之间的动作关系。
**不冻结**：阈值、比例、账户分母、词之间的排他性、任何转移函数。
**边界**：
1. 不是互斥状态机——同一时点可以「大金融锁仓 + 短线试错 + 另一账户不可见」（`7675275728866706274 / 767527-account-boundary`）。
2. 「试错」双重用法：情绪周期阶段词（`7565135321076763938 / 756513-s21-45`「现在你要学情绪。周期了冰点试错主身震荡，退潮高潮」，「主身」为 ASR）与仓位状态（上引「保持原有的试错，仓位啊不要变啊」）。两者结算口径不同，登记时必须标明取哪一种。
3. 四词版本不含试错 → 词表本身不是他严格维护的枚举。

### 裁定 2：锁仓拆四义、登记必须带驱动来源 ✅ 接受（比草案多拆一层）

| 标签 | 判据 | 原话锚点 |
|---|---|---|
| **锁仓（规则内）** | 符合预期分支成立，且事前已带止盈止损 | 8/14 `767382-three-expectation-branches`；2026-04-20 `763071-s0-12`「就是说当你带上了交易系统，你就择了锁仓，就不要害怕第二天吃地板或者是止负反馈」 |
| **滞留（被迫）** | 想动而动不了；**作者原词「被迫锁仓」** | 2026-08-10 `681570-s11-27`「他不想去呃锁仓那个呃出来啊，是因为他被套多了啊，他动不了，所以说他只能被迫在里面躺平啊」 |
| **承诺锁仓（声誉／执念驱动）** | 持有理由是对外承诺或点位执念，不是模式反馈 | 8/13 `767334-lock-commitment`；8/19 `767556-4000-obsession`、`767561-trigger-apology` |
| **（主力锁仓）** | 对手方叙事 | 逐出仓位框架，归 X1 |

**为什么不按「主动/被动」二分**：8/13 他是**主动决定**继续持有的，而且当时是浮盈（「我今天是如愿挣到的六位数啊」）。按盈亏分会把它错分。驱动来源才是决策类型。

**冻结**：四义分立 + 「不带来源标签的锁仓不进入任何执行或统计母集」。
**不冻结**：自动判别方法（只能人工按口播打标）。

### 裁定 3：推仓＝Base 正向语义；「全军出击」＝反例 ✅ 修改后接受（不采纳「推仓只作反例」）

**词条裁定（一次性登记，后续不再逐条声明「ASR 不可消歧」）**：
`推仓位 ＝ 退仓位 ＝ 相对常规开仓量提高暴露`。依据：

- `7531632564613369128 / 753163-s51-69`（2025-07-27）：「比如像，野哥？我是不敢退仓位的但是大盘占上三千五了对吧我？肯定会退仓位的仓位加一个仓位加重了」——**同句自我改写为「仓位加重」**。
- `7557726475514334504 / 755772-s7-46`（2025-10-05）：给出定义（常规每次开仓一至三成，确定性出现才推）。
- `7628182050198527395 / 762818-s8-18`（2026-04-13）：「你，用小资金去试水温到确定性买点的时候你，的确定性买点时候你，去敢于推仓位啊这，就是我跟你们说的盈亏比」。
- `7534671965824175412 / 753467-s41-44`（2025-08-04）：「模式内出现，确定性买点的时候啊这个。时候不管是你第二天他是走好还是走坏你都要敢于试，试推仓位知道吧」。

由此 8/17「超预期退仓位」（`767483-three-way-system`）方向可判定＝提高暴露，与「超预期加仓」同向。**幅度仍未冻结。**

**推仓的完整语义（进入 Base）**：
`前提 = 模式内确定性买点（不是浮盈、不是浮亏、不是叙事）` → `动作 = 相对常规仓加权` → `必须同时声明撤回条件（B1）` → `次日不及预期即撤回新增`（`753467-s50-55`「如果说第二天走的不及预期你在短线里。面你第二天就要及时的离场啊」）。

**「全军出击」单独登记为反例**：`7673060086088417699 / 417699-s0-9`（8/12）：「机构的期货期指数据出来了，信爷今天又加了两千多手多单，我今天打满了呀……我靠，刚刚的我刚全军出击，他就干我嘛。」——公开触发是**不可识别的期指主体叙事**，且未声明任何撤回条件，两条都不满足推仓的定义。

**为什么不按草案原案整体降级**：那会删掉他系统里「平时一至三成、看到确定性才敢压」的盈亏比核心，复刻出一个永远不会重仓的系统，与「忠实复刻」冲突。

### 裁定 4：不冻结任何仓位百分比 ✅ 接受

漂移链：八成（8/07 `540200-s88-92`）→ 最后两成打进去／全军出击（8/12）→ 全军出击＋保留半仓（8/17 `767489-*`）→ 减到三成并提取资金（8/19 `767564-reduce-three-cheng`）。

三条硬限定：
1. 两个账户并存（`767527-account-boundary`）。
2. **作者已宣布停止披露仓位配比**（8/19 `767564-finance-and-capital-risk`「那后，面我也不会再再告，诉我的仓位配比了」）→ 分母在未来语料里也**不会**补齐。
3. 唯一带分母的说法是教学口径：`7522847855829372194 / 752284-s59-70`「你比如说你有十层仓位你，只能买一层或者两层」（试错仓一至二成）。

**冻结**：只冻结动作关系。**不冻结**：全部百分比，一律作「样本口径」登记（带日期与上下文）。
**衍生规则**：将来模拟盘若要定比例，那是**目标系统增强层的 owner 决策**，不得写成复刻结果。

### 卡片 1：右侧波段入场

1. **名称／仓位性质**：右侧波段入场｜**波段仓**。
2. **适用市况**：底部或低位长期横盘、趋势开始向上、基本面无实质恶化的波段候选；不是弱市无条件抄底。
3. **入场条件**：候选 → 大阳线/涨停**激活** → 次日回调或 5 日线附近震荡的**首次入口**；后续只在事前定义的支撑小回调且趋势未失效时分批增加。
4. **加减仓与退出**：不追高；新增暴露失败时只撤回新增部分；不符合预期或趋势失效时退出。亏损后的临时补仓不属于本卡（见卡 4）。
5. **仓位约束**：比例、均线、失效阈值未冻结；不把教学口径写成参数。
6. **原话与出处**：`7513455544188538164 / 751345-s24-36`（2025-06-08）：「我们是偏向于我偏，向于做右侧交易就是做趋。势向上的这个这种模式就是当一个个股在底部，红盘伴随着量价移动的嗯五日线上穿二十。日线的时候并且二十日线三十日，线都拐头向上的时候这个时候就是你的介入点你介入，」；回踩环节 `7522847855829372194 / 752284-s3-31`（2025-07-03 二次回踩/N 字）。
7. **证据分类**：candidate（`H-RIGHT-SIDE-TREND-001-R6`）。
8. **未冻结**：均线定义、底部/横盘、大阳线/涨停、支撑、趋势失效、持有期、证券池。
9. **反例与边界**：1096「一旦被你买进去就是坑，要么你就买不进去」——催化型候选不等于可入场；1097 竞价红开爆量是超预期判定不是右侧激活；不适用于把后排追涨当首次入口。
10. **本轮改动（对草案）**：
    - **删除「红肥绿瘦」**（2025-07—09 共 3 次、2026 年 0 次 → phase_rule 存档）。
    - **520 与本卡分离的依据改为结构性**：退出触发与持有期不同（520 = 5 日线一拐头就走；波段 = 趋势失效，自述可拿三个月），即仓位性质不同，而非「他叫它套利」。

### 卡片 4：禁亏损补仓 ＋ 禁浮盈加仓（Base 第一内核）

1. **名称／仓位性质**：禁亏损补仓 ＋ 禁浮盈加仓｜**全仓位性质通用**。
2. **适用市况**：已有仓位出现下跌、被套或反弹；不替代原因诊断（见第二批卡 11）。
3. **入场条件**：不以「跌了很多/便宜」进入补仓；也不以「已有浮盈」为加仓理由。加仓的**唯一**合法理由是超预期／模式内确定性。
4. **加减仓与退出**：下跌中不补；被套后反弹方向是减而非补；「不足 10% 减一半」只保留方向，基准未定义。
5. **仓位约束**：减半基准、比例、账户分母、反转阈值全部未冻结。
6. **原话与出处**：
   - 最完整表述 `7552015322325699840 / 755201-s2-16`（2025-09-20）：「我们做交易啊，每一次大亏的根源是源自于你内心的不甘心在下跌的时候加仓造成的。每一次都是啊，如果你不加仓，你不会造成这么大的亏损的。……第一笔交易买进去之后，第二笔第三笔不要补。如果说它符合你的预期去上涨了，你才能做确定性的交易，但是也不能浮盈加仓。只有到你的确定性机会出现的时候，才可以退仓位啊」
   - 8/17 `767485-no-loss-averaging`：「跌的时候是不能补的，只有超预期的时候才能是加啊」；8/18 `767527-tech-rebound-exit-rule`：「科技的每一次反弹都是你离场的机会……不要在下跌趋势中补」。
   - 后果描述 `7653441144290394752 / 394752-s20-61`（2026-06-21）：「你回调，的时候你觉。得便宜你？买进去了之后没，有向上打向上，了开始补补补补补啊没有子弹又跌了一，下啊卖了房不不不买了，车补补进入，永久的深渊」。
7. **证据分类**：**stable_core**（`H-AVERAGING-DOWN-BAN-001-R9`）。
8. **未冻结**：10% 基准、减半分母、反转确认、-15% 止损（2025-10 版教学口径，2026 未重申）。
9. **反例与边界（卡面必须写出）**：全语料**没有推翻性反例**；但作者本人在 2025-10-30 教过一条**条件例外**——`7566965615812031714 / 756696-s7-31` 把「每跌 15% 补一笔直到解套」称为被动补仓并拒绝（「因，为到了百分之十五我是，止损的我不会补偿的啊」），`756696-s32-52` 允许**主动补仓**：浮亏约「五个点或者八个点」且「一定，要等到反转，信号出现」（极缩量十字星／T 字 K 线／`756696-s53-64` 放量大阳线穿两三根阴线）。
    **按裁定 0-A：该例外属 2025-10 版，降为 phase_rule 存档，当前 Base 不启用。** 启用需反转信号、证券身份、新增风险预算三者事前冻结。
10. **本轮改动**：① 确认为 Base 第一内核；② **补上「禁浮盈加仓」**（草案漏）；③ 卡面写出条件例外及其「不启用」状态，避免确认出一条比语料更严的无条件禁令。

### 卡片 5：事前锁定退出触发器（五层分账）

1. **名称／仓位性质**：事前锁定退出触发器｜**波段仓为主，套利仓同样要求事前退出条件**。
2. **适用市况**：动作前可以定义唯一反馈窗口与退出条件的交易类型；不是事后为亏损找解释。
3. **入场条件**：动作前绑定时间窗×点位/事件/形态条件。
4. **加减仓与退出**：触发成立即按预设执行；执行与否必须独立记录。
5. **仓位约束**：4000、两天、指数对象、减仓幅度全部未冻结（只作样本）。
6. **原话与出处**：
   - 事前规则 `7673039516600693135 / s14-22`（8/12）：「所以说我所仓选择锁仓两天，周四和周五啊，如果周四和周五他不去上去摸四千点的话，那我这个时候就会按照我的交易系统和预期去减仓啊，这就是我的交易系统和执行点啊。」同条另有形态型触发器「他在这个位置如果红盘的时间啊超过三天至四天，不往上攻的话啊，那就是红周必跌啊。」
   - 撤回 `7675614237133220515 / 767561-trigger-apology`（8/19）：「我不该说锁仓得摸四千点啊」。
   - **建议并列登记的第二个样本**（更接近可操作）：`7675649634917030819 / 767564-tech-exit-and-themes`（8/19）：「是大科技千万不要走出下跌，中继的形态一，旦走出下跌中继形态啊，你不管亏多少都要清仓不然的话你会亏的」。
7. **证据分类**：candidate（`H-TRADING-HORIZON-LOCK-001-R39`、`H-SYSTEM-PRESET-001-R36`）。
8. **未冻结**：时间、点位、指数对象、触发宽度、实际成交。
9. **五层分账（冻结为登记要求）**：

| 层 | 含义 | 8/12—8/19 案 | 可核验性 |
|---|---|---|---|
| L1 事前规则 | 动作前公开绑定的条件 | 锁仓两天；周四五不摸 4000 则减仓 | ✅ 原话 |

### 卡片 6：混沌—退潮—恐慌盘防守链

1. **名称／仓位性质**：混沌—退潮—恐慌盘防守链｜**组合层**。
2. **适用市况**：短线赚钱效应退潮、混沌或恐慌下杀；组合中仍可有机构主导、硬逻辑且趋势未失效的波段仓。
3. **入场条件**：先识别风险占优并关闭追逐轮动的新入口；出现有限修复只允许有限试探。
4. **加减仓与退出**：管住手、控制仓位、等待恐慌盘/情绪拐点；修复时可减仓；短线卖飞不追。
5. **仓位约束**：退潮、恐慌盘、修复强弱阈值未冻结；不得把「没有恐慌盘不会止跌」反推成「出现恐慌盘就可抄底」。
6. **原话与出处**：`7517573542352129332 / 751757-s2-22`（2025-06-19）「我前天说了，这是个混沌期，它混沌期它就它就会杀透，如杀透。没有恐慌盘出来，他是不会止跌的，知道吧？所以一个管住手，第二个控制好仓位。」；组合层行为样本 `7631897916105586147 / 586147-s50-77`（2026-04-23）「现在很小很小也就是说退潮期，的时候哎我基本上不玩，啊……根本不，影，响我呃账户的回，撤的这就是怎么控制回撤」；8/14 `767372-short-term-retreat-warning`；8/19 `767564-finance-and-capital-risk`。
7. **证据分类**：stable_core（`H-CAPITAL-FIRST-001-R4`）＋ candidate（`H-MARKET-CHAOS-RETREAT-001-R5`）。
8. **未冻结**：退潮层级、恐慌盘观测、修复窗口、试探规模、波段仓保留条件。
9. **反例与边界**：与卡 2 分工——卡 2 在题材层**选强**，卡 6 在组合层**降总暴露**。分离的直接证据是同一条作品内的并列：1092 同时给出「我的大金融里面亏也亏不了几个钱……每天就是零点几个点的上下浮动」与「短线开始出现情绪突退潮的迹象啊，要注意仓位管理啊」。
