## §4 唯一入场链（冻结）

设 `C`、`O` 为后复权收盘／开盘，`c`、`o` 为原始收盘／开盘，`MA_k` 为 `C` 的 k 日 SMA。

- **L1 法定涨跌幅**：`limit_pct(code, date)` = `0.20` 若代码前缀为 `688`/`689`；
  `0.20` 若前缀为 `300`/`301` 且 `date ≥ 20200824`，否则 `0.10`；其余 `0.10`。
- **E1 低位**：`(C_a − min(C[a−249:a])) / (max(C[a−249:a]) − min(C[a−249:a])) ≤ 1/3`，
  区间为**含 a 在内的 250 根闭区间**；分母为 0 时视为不满足。
- **E2 激活**：`pct_chg(a) ≥ 50 × limit_pct(code, date_a)` 且 `c_a > o_a`。
- **E3 窗口**：存在激活日 `a ∈ [t−10, t−1]`（闭区间十根，严格早于 `t`）。
- **E4 回踩**：`C_t ≤ MA5(t)`。
- **E5 结构**：`MA5(t) > MA20(t)`、`MA20(t) > MA20(t−1)`、`MA30(t) > MA30(t−1)`，
  且六个量全部有限。
- **E6 单仓**：同一证券同时至多一个持仓；持仓期间不接受新入场信号。
- **E7 一次激活至多一次入场决策**：在 `t` 触发的入场**决策**消耗掉全部日期 ≤ `t` 的激活，
  **无论 `t+1` 是否真的成交**；只有 `t` 之后新出现的激活才能开启新的十日窗口。
  （Codex 第二节点指出的歧义：若只在成交时消耗，一次被涨停挡住的入场会在次日以更高价
  再次尝试，那正是卡 1 第 4 条「不追高」禁止的追价。按「决策即消耗」处理，
  被挡住就是本轮没上车。）
  **E7 补充（同样在运行前写定）**：§3 的宇宙过滤（ST、`.BJ`、因子不可用、历史不足）
  使该证券在该日**根本不在宇宙内**，因此不构成入场决策，**不消耗激活**；
  只有通过宇宙过滤后真正触发的决策才消耗，无论其成交是否被涨停、缺价或窗口末阻断。
- **E8 成交**：`t+1` 开盘买入。若 `t+1` 的**原始开盘价**处于当日涨停价
  （`o ≥ up_limit − 1e−6` 且 `up_limit < 9999`）则该信号**作废**，不顺延、不重试。
  若 `stk_limit` 缺该行，照常成交并置 `entry_limit_row_missing`。
  若 `t` 是窗口最后一根则计 `entry_signal_without_any_next_bar`，不成交；
  这两种情况同样已按 E7 消耗掉激活。

## §5 唯一退出链（冻结）

- **X1 趋势失效**：入场后首个满足 `MA5(u) < MA20(u)` 的 bar `u`（两者均有限）。
- **X2 成交**：`u+1` 开盘卖出。若该 bar 原始开盘价处于跌停价
  （`o ≤ down_limit + 1e−6` 且 `down_limit > 0.02`）则**顺延**到下一根可成交 bar；
  原始开盘价非有限或 ≤0 的 bar 一律不视为可成交。
  若 `stk_limit` 缺该行，照常成交并置 `exit_limit_row_missing`。
- **X3 窗口内始终无退出信号，或始终卖不出** → `status = open_at_window_end`，
  按窗口末根 `C` 计价。
- **X4 退出信号落在窗口最后一根、无下一根可成交** → `status = no_fill_fact`，
  收益记 NaN，**不计入主口径**。
- **X5 无止损、无止盈、无时间止损、无分批。**
- **X6 停牌**：停牌日在 `daily` 面板中无行，「下一根可成交 bar」自然跳过；
  由此产生的延迟计入 `entry_delay_days` / `exit_delay_days` 披露。

## §6 执行与费用（冻结）

- **可成交性判定用原始价**（`o`、`stk_limit`）；**经济收益用后复权价**（`O`、`C`）。
- A 股 T+1：入场在 `t+1` 开盘、退出信号最早只能在入场当日之后的 bar 成立并于其次日成交，
  规则构造上不可能同日买卖。
- 费用模型（`CostModel`）：佣金 `0.00015`、单笔地板 `5.0` 元、过户费 `0.00001`、
  印花税 `0.001`（仅卖出）、滑点 `0.001`（双边）。
  **交易级地板按一手 100 股名义额评估**（交易级没有仓位分母，沿用卡 8 预注册 §9.3 口径）。

- 所有入场／退出条件只用决策日**收盘时可得**的数据：均线、斜率、区间位置、`pct_chg`、
  当日 `open`/`close` 全部属于当日或更早。
- 成交价一律取决策日之后的 bar。
- ST 判定按信号日的 `namechange` 区间，不使用未来改名。
- 涨跌停价取成交 bar 当日的 `stk_limit`，该 bar 当日盘前即已公布。
- PIT 免责：单一终端 vintage 按 `trade_date` 截断，**算法层 as-of 可证、知识时点层 PIT 不可证**。

## §10 随机性与 placebo（冻结）

- 设计：`m3_520.matched_horizon_placebo` —— 同证券、同窗口、同已实现持有 bar 数、
  随机入场时点，比较随机入场组合的均值分布与实际均值。
- **reps = 200**；**样本内 seed = 1120260823，样本外 seed = 1120260923**（= 样本内 +100，
  沿用卡 8 的 seed 派生方式）。
- **`warmup_bars = 250`**：placebo 的随机入场只从索引 ≥250 的 bar 抽取，
  与本规则 §3 第 4 条的可入场跨度一致。
- **p 值公式（逐字冻结，Codex 第二节点要求）**：

  ```text
  p = (1 + #{ placebo_mean_i >= actual_mean }) / (usable_reps + 1)
  ```

  - 比较算子为 **`>=`**：并列（`placebo_mean == actual_mean`）**计入**分子，方向保守。
  - 分母是 **`usable_reps + 1`**，其中 `usable_reps` 是实际产生了至少一个抽样收益的
    重复次数，可能小于 200（某些证券在窗口内放不下该持有期时该笔被跳过；
    若某一 rep 一笔都放不下则该 rep 不计入）。`usable_reps` 必须在结果中披露。
  - 判据用 **`p ≤ 0.05`**（含等号）。
  - 不使用 `#{...} / reps` 这一未修正写法；两者在 0.05 边界可给出相反结论，
    因此在此明文选定并锁死。
- placebo 用**毛收益**比较（与卡 8 一致：随机入场组合的费用结构与实际一致，
  不影响上尾秩序）。

## §11 判据（冻结，四项全过才算交易级通过）

1. 样本内 `mean_net_return_pct > 0`；
2. 样本内 placebo 上尾 `p ≤ 0.05`；

样本外是最终裁决窗口；把样本内也设为硬门是**更严格**且事前承诺的，
消除了事后挑窗口的余地。§9 的披露项一律不设门。

## §12 失败分支与允许的结论

**任一判据不过** → 标记「研究候选 / 未通过」并封存。禁止：调参重试、换趋势失效定义
（增强合同已具名并否决 `MA20` 拐头向下这一备选）、加过滤、改切分、改 placebo、
延长样本。**不进入组合级。**

**四项全过**，允许的结论**只有一句**（措辞按 Codex 第二节点的估计对象校正）：
> 在本闭环的退出规则所决定的持有长度**给定**的条件下，该入场链选出的**入场时点**，
> 相对同证券、同窗口、同持有长度的随机入场时点，携带信息。

**为什么必须这样窄**：placebo 固定了每笔真实交易**已实现**的持有 bar 数、只随机化入场时点。
因此它检验的是「给定这个持有长度，入场时点是否选得比随机好」，
**不是**入场与退出两条规则的联合信息贡献，**更不是**「趋势失效」这条增强定义本身被验证。
退出规则的价值只能由组合级与后续消融回答。

明确**不允许**的推论：不等于组合级可盈利；不等于「趋势失效＝`MA5<MA20`」这一增强定义
得到独立验证；不等于卡 1 晋级或证据分类改变；不等于可进入 `backend/playbook/`、
模拟盘、飞书或任何券商路径。

## §18 运行后更正说明（2026-08-23，审计强制，仅追加）

> 本节按 §16「出现可复现的实现或数据故障：记录作废原因，按同一预注册重跑一次」追加。

Codex 唯一一轮正式审计产出 0 P0 / 6 P1 / 0 P2 / 0 P3，其中两条使首次运行的数字失效：

   首版实现按 §5 的宽读法从 `entry_index` 开始搜索。
   **裁定：文本优先于代码，且 §6 是两处中明确的一处**，采纳 §6 的读法——
   退出信号最早落在 `entry_index + 1`，最短持有由 1 个 bar 变为 2 个 bar。

   **入场根的复权因子**：入场腿还原为原始成交价，退出腿还原为该原始一手在期间公司行为后的
   真实价值，毛收益比值不变，地板落在真实一手名义额上。`CostModel` 未改动，
   卡 8 的既发布结果不受影响。
