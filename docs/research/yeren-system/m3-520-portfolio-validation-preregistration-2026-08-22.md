## 3. 主曲线口径（owner 已裁定）

- **主曲线 ＝ 全部机械有效信号都入场**（经 §2.7 门控与槽位约束后实际成交的每一笔）。理由：这是规则字面可执行的真相；金叉是否成立只在退出后事后可知，事前筛选等于后视。
- **归因子曲线 ＝ 只含 S8 主口径 (c)（金叉成立）交易的假想并列曲线**，披露用，不参与判据。两条曲线并列展示，差异本身也是产出（它就是那六成「不属本卡语义」交易对组合的贡献）。

## 4. P4 回撤与其他指标的定义

| 指标 | 定义 |
|---|---|
| 最大回撤（P4） | 日频收盘标记权益曲线上的最大峰谷跌幅，分窗口报告；**不设阈值** |
| 年化净收益 | 几何年化（按窗口内实际交易日数折算），扣全部费用 |
| Sharpe | 日频净收益序列年化（无风险利率取 0，声明这是简化） |
| 敞口 | 持仓市值／权益 的均值与最大值 |
| 其他 | 成交笔数、被丢弃信号分类计数（满槽／已持仓／涨停作废／ST 作废）、换手概览、逐年分解 |

单笔 MAE 与组合最大回撤**继续分栏**，不得合并表述（原预注册 §5 的规定升级适用）。

## 5. 判据（跑之前写死）

1. **必要条件**：样本外年化净收益 > 0。
2. **回撤与曲线形态不设机械阈值**：可承受与否由 owner 看报告裁决——任何具体阈值（如「≤25%」）都是研究者发明的数，违反本项目纪律。
