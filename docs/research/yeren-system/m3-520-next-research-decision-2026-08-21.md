**S5 的证据（事实层）。** 卡 8 引用的 `767570-520-arbitrage-exit`（sentences[31:52] 拼接）里有这一句：

> 「的是技术败的钱当五，日线上穿二十线完全。成立的时候啊我们的离场点就是五日线只要一，点点拐头我们就走一点点鬼。头就走完了完全离，场点就是五十线啊下穿二十线」

去掉 ASR 断句噪声后的字面序列是：**「……挣的是技术面的钱。当五日线上穿二十日线完全成立的时候啊，我们的离场点就是五日线只要一点点拐头我们就走；一点点拐头就走。完全离场点就是五日线下穿二十日线。」**

**解释层（researcher-added）**：这句读起来是一个三段结构——① 在「即将上穿」处入场；② **等上穿完全成立**；③ 成立之后，五日线一点点拐头就走，彻底走人看下穿。也就是说，「上穿完全成立」可能是退出触发器的**布防条件**，而不只是叙述背景。

**这与第一轮实现直接冲突（事实层）。** `scripts/yeren_research/m3_520.py:145`：

```python
early_exit_signal = np.isfinite(short_slope) & (short_slope < 0)
```

主退出只要求「入场后五日 SMA 首次转降」，**完全不要求 5SMA 曾经上穿过 20SMA**。而入场条件（同文件 136–144 行）恰恰要求 `ma_short < ma_mid`，即入场时必然在上穿之前。两者相加的结果是：**一笔只要在上穿发生前五日线抖一下就被平掉，也计入 132,944 笔完成交易**。这类交易在作者的叙述里没有对应物——他描述的那个交易是「上穿成立之后才开始盯拐头」。

**S6 的证据（事实层）。** 同一段话稍后作者自己做了一句总结：

> 「就是上车点是五日线上穿二，十日线下这个点是五日线下穿二十点」

即**「上车点是五日线上穿二十日线，下车点是五日线下穿二十日线」**（「下这个点」按上下文为「下车点」的 ASR 误识）。这是一个纯粹的 5/20 金叉—死叉读法，和前面「即将上穿才是入场点、完全上穿之后再进就比较迟了」是**两种不同的入场时点**。战法名「五二零」字面即 5 与 20，这条读法不能被当成口误直接丢掉。

**第一轮报告与卡 8 都没有登记 S5、S6。** 报告第三节只写了 early-turn 主规则与 full-cross 诊断退出两种读法；卡 8 第 3、4 条也只写了「即将上穿入场」「一点点拐头就走」。这不是回测口径问题，是**复刻语义的登记遗漏**。

## 三、A 能具体解除哪个阻塞

A 解除的不是「参数没调好」，是**「第一轮检验的对象可能不是作者说的那个交易」**这个更上游的阻塞：

1. **S5 若成立**（退出触发器需上穿成立后布防），则第一轮 OOS 的 132,944 笔早退出交易里，凡在上穿发生前就被平掉的，都**不是**作者描述的 520 交易。它们的均值、中位数、胜率、placebo p 值全部作废——不是"结果不好"，是"算错了对象"。
2. **S6 若成立**（作者自认的上车点是上穿本身），则入场时点整体右移一格，是另一条需要独立检验的规则，而不是同一条规则的参数扰动。
3. **S1 若查明「三十天」是 30 日线、是下跌背景长度、还是 ASR 错分**，则 `--stop-days 30` 这条敏感性要么被取消（不是一种合法读法），要么被改写成别的条件。第一轮已证明这个数会把样本从 132,944 压到 724 笔并反转方向——**未冻结的语义在这里直接决定样本**，不能留着。
4. A 完成后，B/C/E 才有一个**唯一确定的检验对象**；否则 B 会得到「raw 与 as-of 下哪条规则更好」这种四选一的结果表，正好是研究纪律禁止的按结果择优。

## 四、为什么不先做 B / C

- **B（复权）**：D1/D2 表明数据齐备但**档案自证不了 as-of 因果性**（2,779/2,826 快照为一次性回填、每 trade_date 仅 version 1）。B 的结论多半是「后复权型 as-of 序列在语义上因果，但本档案无法用版本历史验证厂商未修订」——这是一条限制性结论，不改变现在该检验哪条规则。且若 S5/S6 未定，B 会产出 raw×as-of × 两种退出 × 两种入场 = 8 组结果表，制造择优诱惑。
- **C（可成交性）**：同理，stk_limit 全窗齐备使 C 随时可做；但 C 的产物是一份保守成交口径，作用于「已确定的规则」。规则未定时先固化成交口径，等于把研究者的执行假设锁在错误对象上。
- 二者都**不会因为等 A 而失效**：数据是 append-only 本地档，不会过期。

## 五、为什么 D、E 继续暂缓

- **D**：P1–P3 由作者语料决定，不由研究决定。当前 1,110 条 transcript 里是否存在套利仓分母的表述，本身应作为 A 的一个附带检索项（见 6.2 A-1c），而不是自己补一个等权组合。**在 owner 明确授权研究假设、或语料补齐分母之前，D 不开工。**
- **E**：接手文档已定调——没先解决语义/复权/执行口径，跑更长 walk-forward 只提高数字精度、不提高复刻忠实度。补充一条本次审计得出的具体理由：**S5 未定时，walk-forward 的样本构造本身是错的**，窗口再多也放大同一个错误。E 只在「口径与预注册规则被一次性固定」之后跑一次，且禁止用 OOS 均值反选口径。
