# M2 首批战法卡片 Owner 审阅索引（2026-08-20）

审阅顺序：先总体仓位语言，再按卡片 1—6 逐项确认。当前只需确认 Base 复刻语义；比例、阈值、证券池与确定性规则留到后续阶段。

## 总体仓位语言

1. 是否接受“空仓 → 试错 → 加仓 → 锁仓 → 推仓”是行为语言而非生产状态机？
2. “锁仓”是否拆成主动持有与被迫锁仓？
3. “推仓”是否只保留为风险极值/反例，不作为目标系统正向状态？
4. 是否同意仓位比例全部留待 M3，当前只冻结动作关系？
