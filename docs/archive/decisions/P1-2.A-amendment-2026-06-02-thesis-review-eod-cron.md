## 触发原因

`P0-10-amendment-line2-2026-06-01` §1.2(方向② 阶段1)要求一条**新 EOD Line-2 复盘 cron**(~17:30,MiroFish postclose 17:00 之后):LLM 比对当前证据 vs 原 `PositionThesis` 支柱 → intact/weakening/broken + 理由文本,**仅写 evidence + display-only 飞书 digest**,owner 据此人工执行。owner Round-1 已选「advisory 先」。该 cron 是 P1-2.A BrokerScheduler 的派生扩展。

理由(同 evolution_shadow_run 先例):

- 复用已锁定的单实例 BrokerScheduler(避免新起 scheduler 进程的运维复杂度)。
- 17:30 在 EOD chain 16:00:30 + advance_day 16:30 + MiroFish postclose 17:00 之后,当日证据(含 MiroFish 复盘)已落库,复盘读到最新材料。
- 与现 8 cron 时间错峰不冲突。
- 触发 `P0-10-amendment-line2-2026-06-01` §1.2 的 LLM advisory 主链路。
