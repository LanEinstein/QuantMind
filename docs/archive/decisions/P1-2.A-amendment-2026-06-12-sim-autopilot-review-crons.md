# P1-2.A amendment(2026-06-12):模拟盘自动驾驶复盘 cron 族(盘后归因 + 周末/节假日 lane + sim 自动对账)

> 状态:**已锁定**(owner 2026-06-12 需求 1:"非交易时间〔盘后/周六日/节假日〕进行复盘与自进化")。
> 变更对象:P1-2.A(BrokerScheduler cron 集,当前 9 个全部 trading-day/hours gated,周末/节假日零 job)+ P0-5(16:00 对账从未接线,owner-initiated only)。

## 1. 决策(锁定)

### 1.1 新增 cron(BrokerScheduler)
| cron | 时间 | gating | 职责 |
|---|---|---|---|
| `daily_attribution_review` | 交易日 18:00 | is_trading_day | 当日逐笔归因复盘 → ReviewRecord store(§1.3) |
| `weekend_deep_review` | 周六 10:00 | **非交易日才跑**(新 gating 类型) | 周度绩效汇总 + 实验规划 + 长任务回测/参数搜索 |
| `holiday_catchup_review` | 周日/节假日 10:00 | 非交易日 + 周六 run 失败/未跑才补 | 补跑窗口 |
| `sim_auto_reconciliation` | 交易日 16:10 | is_trading_day + **仅纯 sim 模式** | §1.2 自动对账 |

### 1.2 sim 自动对账(自完整性校验)
纯 simulation 模式下镜像即权威,对账转为**自完整性校验**:16:10 比对 EOD snapshot ↔ broker 派生态 ↔ equity point;**零差异 → 自动 RESOLVED_SYSTEM_AS_TRUTH**(确定性,append-only 留痕);**任何差异 → OPEN ticket fail-closed 冻结 + 飞书告警**(差异=程序 bug 信号,必须人工看)。feishu_interactive 模式下对账语义不变(人工 decide)。

### 1.3 ReviewRecord store(归因复盘存储)
- append-only;**facts-first**:逐笔 entry/exit 价 vs 当日 VWAP、触发器命中/被吞、滑点、持有期收益、policy_hash、style、违规/拒单计数;
- "错过信号"反事实默认 **non-promotable**;仅预注册信号(实际产出过的 HOLD/被拒单)可作晋升证据(codex P2-6,防后见之明);
- 作为 Phase AB 客观晋升的证据源之一;LLM 可读不可写(LLM 复盘文本只入 evidence_collection,既有 4 类权限不变)。

### 1.4 周末/节假日 lane 的 ops 门(全部满足才跑,否则 skip + audit)
无 OPEN 对账票 / 最近 EOD snapshot checksum 有效 / artifact store 干净 / 磁盘余量 ≥ 阈值 / LLM 预算余量(周末实验计同一 `llm:usage:{utc_date}` 计数器,不绕 ¥100 cap)/ 数据新鲜度门 / **距下一开盘 ≥2h 内不做任何激活动作**。

Phase AA(AA-001..AA-005)。新 cron 均一次失败一次重试 + audit;周末 lane 失败不冻结交易(进化与交易解耦,沿用 X-005 先例)。
