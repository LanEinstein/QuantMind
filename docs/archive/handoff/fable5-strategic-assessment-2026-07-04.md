## 0. 三句话答案

1. **§5 Q1(DSR≥0.95 可达吗):不可达 —— 可证明、永久、候选无关。** 依据不是「试了十几个都失败」的经验归纳,而是纲领自己的收益盲算术(AP-0.5):过门需年化 Sharpe **2.67**(最松口径 1.66),而 ≤5 长-only A 股集中书的结构天花板 ~0.5–0.8;要把门槛压到可及范围需再等 **~70–185 年**数据,且账本 N 只增不减。**每一个未来 dev 候选的 DSR 门结果,在开跑之前就已由算术判定为 FAIL。**
2. **但「不可认证」≠「不存在」。** 门回答的是**可认证性**,不是**存在性**。年化 Sharpe 0.3–0.6 的真边可能存在且有经济意义(反转 eq_5 十年 +571k vs CSI300 +176k),只是在 2418 试验债 + ~10 年样本下统计上无法与运气区分。**「找一个能过四门的排名 alpha」这个目标应正式关闭**;按原判据继续 D3/D4 式搜索 = 在算术上已判负的游戏里继续下注,且每刀还加深账本债。
3. **§5 Q2(产品重定义):是,但分层,不是二选一。** 地基 = 已验证的「防御宇宙过滤 + 现金 buffer」sleeve(其承重主张是**风险性质**,近乎机械可验证);其上叠一个**可选、非承重**的排名层,用选拔制判据(胜 placebo)+ 前向认证决定去留。**D2 是裁决排名层生死的唯一值得跑的实验**(按 §3.2 重新定性后跑,不是按原四门跑)。

## 1. Q1 的证明(算术,不是经验)

三条独立论证,互相咬合:

**(a) SR_req 是候选无关的。** AP-0.5 的收益盲反解只依赖 N(账本 2418,只增)、T(497 个 rebalance 期 ≈ 10 年)和矩假设,与「测哪个因子」无关。主口径 SR_req 年化 **2.67**;把 HAC 拉到最松(IID)仍 **1.66**;对 SR_ref 乐观上抬到 0.5 仍 NO-GO。这意味着 D2、D3、D4、分析师修正动量、以及任何尚未想到的候选,**都面对同一堵墙**——AP-0.5 对复合的 NO-GO 判决,逐字适用于剩余全部候选池。

**(b) 时间上永久。** SR_req ∝ ~1/√T(N 固定)。要把年化 2.67 压到 0.62(K·SR_ref 门槛)需 T×18.5 ≈ **185 年**;最松口径(1.66→0.62)也需 T×7.2 ≈ **72 年**。而现实中 N 还在随每次试验增长,方向只会更差。数据回补也无解(statements 存档始于 2015,前面没有了)。

**(c) Sharpe 天花板结构性低于门槛。** Grinold 宽度:~50 次/年 rebalance × 5 个高度相关的长-only 持仓,T+1、无杠杆、无空头、单边做多 A 股。这个书的诚实天花板 ~0.5–0.8;实测十年最优 0.31。年化 2.67 属于高频/多空/大宽度策略的量级,全部超出 scope(永禁真实下单 + 数据 + 市场结构)。

**经验完全确证算术**:round-1..4 + alpha-pivot + DS-D1,12+ 候选 DSR 全部落在 0.001–0.05,无一例外——正是「真边 0.3 量级 + 门槛 2.67」下算术预测的样子。

**门没有坏。** 它三次精准预言 OOS 失败,作为「样本内证据能否认证技巧」的回答它始终诚实。坏掉的是**期望**:期望它最终会放行什么东西。它现在的功能等价于一堵永 FAIL 的墙——继续把它当 promotion 门,纲领就**不存在任何可能的成功出口**,这是流程缺陷,不是研究不够努力。

## 2. 第二层硬事实:95% 置信的前向认证同样不现实(owner 必须知道)

预注册冻结的候选在处子前向窗口零 deflation 债(N=1),这是账本墙的唯一豁免通道。但均值收益的统计规律依旧:**期望 t ≈ SR_ann·√years**。

| 真边(年化 SR) | 前向 1 年期望 t | 3 年 | 达到 t≥1.645(95% 单边)约需 |
|---:|---:|---:|---:|
| 0.31(实测反转) | 0.31 | 0.54 | ~28 年 |
| 0.62 | 0.62 | 1.07 | ~7 年 |
| 1.00(不现实的好) | 1.00 | 1.73 | ~2.7 年(80% power 还要更长) |

**结论:在这个 Sharpe 量级,没有任何统计程序——样本内或前向——能在可行时间内以 95% 置信认证「平均收益边」。** 这不是本纲领做错了什么,是低 Sharpe × 短历史的普遍数学。产品决策不能以「先统计认证再上」为前提,否则等于无限期不决策。

**但存在一个关键不对称,它是整个对策的统计学根据:**

- **风险性质可以快速验证**:暴露、beta、波动在几周~几个月的日频数据内收敛;现金 buffer 的 MDD 控制**近乎机械**(frontier 实测 MDD ∝ 暴露:40% gross → 市场崩 45% 时 sleeve 回撤被暴露上界钉住)。
- **收益均值性质需要几十年**(上表)。

→ **把产品的承重主张放在风险性质上(可验证),把收益边降为披露与监控项(不可认证)。** 这就是 §3 分层的依据。

## 3. 对策:三层架构

### 3.1 地基 = 防御 sleeve(承重主张 = 风险控制)

**定义**:防御宇宙过滤(排除门:高波/彩票 MAX/低质量/PIT-ST/四件套)+ ≤5 集中 + 永久现金 buffer(40% gross 档为部署原型)。**不主张排名 alpha**;宇宙内选择用最简单的确定性规则(D2 结果决定用反转还是最低换手规则,见 §3.2)。

**证据**(已在库,无需新实验):D1 buf40_5 MDD **14.78%**(vs CSI300 45% / 全宇宙反转 54%)+ 熊市累计正;B2 永久现金 sleeve 净盈翻倍 + MDD 减半;frontier 证 buffer 是唯一 MDD 杠杆且 ≤5 集中最优(owner P-E 被数据印证)。

**判据(需 owner 批,amendment)**:绝对净盈 > 0 + 熊市累计 ≥ 0 + MDD ≤ 暴露推出的目标上界 + 前向确认。**胜 placebo / DSR 是「排名 alpha 主张」的门,对一个不主张排名 alpha 的产品不适用**——但照算照披露(诚实:D1 显示宇宙内随机比 D1 排名更赚,说明价值在宇宙+容器,不在排名,这正是 sleeve 定性的依据而非污点)。

### 3.2 排名层 = 可选、非承重,由 D2 一刀裁决

**D2 重新定性**:它回答的不是「能不能过四门」(不能,§1 已证,预声明这一点),而是「**排名层是否配得上叠在 sleeve 上**」。判据 = 胜同宇宙随机 placebo(paired-t ≥ 2)+ 熊市/股灾切片改善 + MDD 不劣化;DSR/SPA 照算照披露、不作 promotion 门。

**必须补一条臂(证据洞,本次审阅发现)**:**A0 纯反转 vs 全宇宙随机 placebo(exposure-matched)从未测过**。QGR-3 验证的是 IC 符号(截面层);C1a/QGR-4 的 placebo 全在 EXIT 层;frontier 无 placebo 臂;D1 是第一个带随机排名 placebo 的候选——而它证明了 IC 层有效的因子可以在 top-5 书层**输给随机**,且 D1 的随机臂 +1.49M 强烈暗示宇宙+轮动本身携带大部分价值。**纲领唯一的「已验证排名边」其实没验过书层 placebo。** D2 的 ablation 必须补上这条臂,一次回答两个宇宙的问题。

**预注册三分支决策树**(评测前落 spec,hash 定死):

- **(a) D2 胜 placebo + 熊市/股灾改善** → 排名层入围:冻结 spec → 送前向队列(§3.3),sleeve+反转排名成为产品形态。
- **(b) D2 输 placebo、但 sleeve 指标成立** → 排名层弃;产品 = sleeve-only,宇宙内选择退化为最低换手确定性规则(如 dv_ratio top-5 等权、季调)。
- **(c) A0 本身也输全宇宙随机** → 「反转 = 已验证排名边」被推翻(其 +571k 主要是宇宙/轮动/暴露效应);排名层整体死刑,产品 = sleeve-only + 对既往定性作重大修正记录。

**成本**:候选池里信息/成本比最高的一刀——复用 D1 全套件 + A0 panel,零新因子代码,一次 ablation append 账本。

### 3.3 认证 = 全部移到前向:预注册 + kill-switch

- **冻结于窗口之前 → 该窗口零 deflation 债**。这是账本数学下唯一干净的认证通道,且比样本内 DSR 更严(要真等、无法 p-hack)。
- **认证形式 = 「按设计运行」的存活认证**,不是 t≥1.645(§2 已证后者不可行):预注册风险 kill-switch(MDD 超上界 / 熊市亏损超阈 / 相对最简基线持续劣化 N 个月即停)+ 收益作监控披露。风险性质几个月内即可证实/证伪(§2 不对称),这正是 sleeve 作地基的原因。
- **前向弹药管理**:sealed test 第 5 次不烧;**FW look-once 不烧在 ffc1db3 上**(round-4 候选是 benchmark-relative 增强指数,≤5 绝对框定装不下,为它花稀缺一枪不值;且 accrual-gated ~2026-08)——稀缺前向资源留给 §3.2 的胜者。

## 4. 不做什么(与做什么同等重要)

| **D3 / D4** | **默认跳过** | 与 D1 同族(防御排名);D1 机制(过滤器有效、排名器无效)预测其同命;每刀加深账本债。仅当 D2 给出意外证据再回访。 |

## 5. 请 owner 拍的三个决定

1. **【判据架构 amendment】** 认可「**dev = 选拔,前向 = 认证**」:四门全保留、每刀照算照披露、账本继续 append(**四门不放宽、不清零,一字不动**);但正式承认 DSR≥0.95 的样本内不可达性(AP-0.5 算术为证),promotion 决策改基于「选拔制判据(placebo/切片/MDD)+ 预注册前向存活认证(§3.3)」。先例:2026-06-27 弃 MDD≤8% 硬门 amendment——同样是「门本身结构不可达」的判据重定。
2. **【产品分层批准】** 批准 sleeve 地基判据(绝对净盈 + 熊市不亏 + 机械 MDD 上界 + 前向确认;placebo/DSR 披露不作门),并接受 **sleeve-only 是合法的产品终态**(若 D2 走分支 b/c)。
3. **【D2 授权】** 按 §3.2 重定性协议跑 D2:补 A0-vs-全宇宙随机臂 + 预注册三分支决策树 + DSR 预声明必 FAIL(照报)。

**若 owner 只批其中之一,优先级 = 1 > 3 > 2**:决定 1 是前提(否则 D2 跑完仍面对永 FAIL 的门,结果无处安放);决定 3 的成本最低且无论走哪个分支都把「排名层存废」钉死;决定 2 可等 D2 结果后再拍。

## 6. 红线自检

- **四门不放宽**:门全保留、全披露、照跑照报;改变的是 promotion 的决策依据,经 amendment、owner 拍板——这是同时满足「不放宽」与「不自欺」的唯一方式:门照跑,但不再假装有候选能过。
- **账本不清零**(D2 照 append)· **committed spec 评测前 hash**(D2 三分支预注册)· **FAIL 报 FAIL**(DSR 预声明必 FAIL 照报)· **train_val only**(D2 不碰 sealed test)· **push / 摄取 / look-once / live 全 owner-gated** · 研究零 LLM · 永禁真实下单——全部不变。
