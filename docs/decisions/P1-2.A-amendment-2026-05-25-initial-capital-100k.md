# P1-2.A 修订 — 2026-05-25 MockBroker 初始本金 ¥100 万 → ¥10 万(镜像同花顺模拟盘)+ 生命周期重置剧本

> **修订基准**: [P1-2.A MockBroker 持久化(混合 delta+EOD 快照 + 双 Applier + BrokerScheduler)](./P1-2.A-persistence-hybrid-snapshot-and-broker-scheduler.md)
> **关联**: [P0-1 simulation 底座 + feishu overlay](./P0-1-simulation-base-feishu-overlay.md) §1.3(切换/重置 = 账户生命周期事件)+ [R0 §5](./R0-two-line-rearch-provenance-and-single-builder-2026-05-24.md) 安全地基
> **修订日期**: 2026-05-25
> **触发**: 双线 MVP go-live 把 MockBroker 定位为 owner **同花顺模拟盘(预算 ¥10 万)的单一镜像**。现 `config/broker.yaml mock.initial_capital = 1_000_000` 与之不符。Codex 红队指出:`backend/broker/persistence/recovery.py:285` 在**有快照时用 `snapshot.initial_capital`**,裸改 YAML + 重启**不会重置**既有镜像 → 必须走账户生命周期重置。

## 1. 修订前

- `config/broker.yaml`: `mock.initial_capital: 1000000`。
- `BrokerScheduler.__init__(initial_capital=1_000_000.0)` 默认 + `backend/main.py` 注入。
- `recovery.py`: 有 `BrokerSnapshot` 时 `RecoveredState.initial_capital = snapshot.initial_capital`;无快照才用传入 `initial_capital`。

## 2. 修订后

### 2.1 配置改值

- `config/broker.yaml`: `mock.initial_capital: 1000000 → 100000`。
- `BrokerScheduler` 默认 + `main.py` 注入对齐 `100_000.0`(单一真相源仍是 broker.yaml;默认值仅 fallback)。
- 其余 broker.yaml(commission/stamp_tax/slippage_by_board/transfer_fee)**不变**。
- ¥10 万 = `budget_tiers` 的 **Normal 档**(≥¥1 万,见 P0-7-amendment),P0-7 仓位三连(单股 ≤15% / 总仓 ≤70% / 单次 ≤5 万)**原样适用**。

### 2.2 生命周期重置剧本(**必须执行,非裸改 YAML**)

改本金 = **账户生命周期事件**(P0-1 §1.3)。部署/重启前按序:

1. **冻结** —— 设 `mode_switch_in_progress=True`(Builder 第一道早返 + SimulationExecutor freeze 拒所有新 BUY/SELL 路由)。
2. **归档旧状态** —— 写 `MODE_SWITCH_RESET` BrokerEvent(含当前 cash + positions + 旧 initial_capital),供 recovery 重建时间线。
3. **重置 MockBroker** —— `MockBroker.reset_to_snapshot` 到 ¥10 万 baseline 空仓(覆盖必经 `ReconciliationApplier::reset_to_snapshot`,严禁直接 mutate `_cash`/`_positions`/`_trades`)。
4. **审计** —— 写 `MODE_SWITCH_INITIATED` + `MODE_SWITCH_COMPLETED` 生命周期对。
5. **解冻** —— 清 `mode_switch_in_progress`;新窗口从 ¥10 万空仓起步。

**owner 确认项**:同花顺模拟盘当前 = ¥10 万初始、**空仓起步**。若已有持仓,改剧本为「重置到 ¥10 万 baseline 后,按 owner 实际持仓走一轮初始对账(`RECON-{date}`)把镜像对齐到真实持仓」,而非直接信任 owner 报数(fail-closed 对账精神,P0-5)。

### 2.3 安全核心不变

- MockBroker 单一镜像;覆盖必经 `reset_to_snapshot`;append-only broker_events 8 红线不破。
- config runtime 不可改 + hot-reload 禁用;本次改 = git diff + 本 amendment + 重启(+ §2.2 重置)。
- 永禁真实下单;¥10 万是**模拟盘镜像额度**,非真实资金。
