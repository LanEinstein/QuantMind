# QuantMind 决策文档目录

本目录用于存放后续已经确认下来的项目决策文档。

建议只放已经定稿的内容，例如:

- 数据源选择结论。
- 券商接口选择结论。
- 自动化交易边界。
- 风控红线。
- 第一阶段策略范围。
- LLM 与 Kimi thinking 使用边界。
- 回测与模拟盘验收标准。

命名建议:

```text
YYYY-MM-DD-topic.md
```

例如:

```text
2026-05-08-market-data-source.md
2026-05-08-live-trading-boundary.md
```

未定稿的调研清单和过程分析仍放在 `docs/` 或单独的工作目录中，不放入本目录。
