## 决策摘要

QuantMind 第一阶段 MockBroker 估值与数据协议采用 **30s 同步 watchlist_snapshot intraday MTM + per-position 明细 EquityPoint + DataQualityProvider per-stock 按需查询 + daily_state on-demand 装配** 架构,满足 P0-6 EquityPoint ≥1/日硬门槛 + P0-7 RiskEngine 纯函数 + P0-8 DataQualityState 早返第四种冻结 + P1-2.A 持久化与 EOD chain 编排多决策的协同要求:

1. **intraday_mtm 30s cron**:`BrokerScheduler` 新增第四个 cron(与 P1-2.A 的 `eod_pipeline` / `mirofish_postclose` / `advance_day` 并列);`* */30 * 9-15 * * mon-fri Asia/Shanghai`;集合竞价(09:00-09:25)与午休(11:30-13:00)按 trading_hours 内置 gating 跳过;每次写一条 `EquityPoint(point_type='INTRADAY')` 到新 `equity_points` collection;~360 点/交易日 ≈ 90k/年(Mongo 容量充裕)。

2. **EquityPoint per-position 明细 schema**:`equity_points` collection 每条记录含 `trade_date` + `captured_at` + `point_type` + `cash` + `frozen_cash` + `positions_value` + `total_equity` + `positions: list[PositionMTM]`(每持仓 code/volume/cost_price/mark_price/market_value/unrealized_pnl/price_source/staleness_seconds)+ `mark_quality` + `degradation_reason` + `last_broker_event_id` 反向索引(连 P1-2.A `broker_events` 实现 replay 验证)+ `schema_version`;**全 frozen Pydantic v2 strict + extra="forbid"**(继承 P1-2.A §2 红线 15 immutability)。

3. **mark_quality='degraded' 触发条件**:任一持仓 code 的 `mark_price` 通过三级回退路径(Redis watchlist_snapshot ≤60s → Mongo `watchlist_market_snapshots` ≤300s → `last_known_price` cached)走到第三级即标 `mark_quality='degraded'` + `degradation_reason='primary+backup_unavailable_for_{code}'`;`positions_value` 仍按 `last_known_price` 计算(避免 cost_price fallback 与市场状态脱节);保证 EquityPoint 写入连续(P0-6 验收 ≥1/日不中断)。

4. **eod_pipeline verify_equity_point 步插入**:P1-2.A `_run_eod_pipeline` 在 `chase_poller_terminal`(16:00:30)与 `acceptance_report`(16:00:35)之间插入新步 `_step_verify_equity_point`;查询 `equity_points` 当日是否有点 → 无则写 `point_type='EOD_FALLBACK'` + `mark_quality='degraded'` + `degradation_reason='no_intraday_point_for_trade_date'`;保证 acceptance_report 总能读到 EquityPoint(P0-6 §1.3.3 硬门槛)。

5. **DataQualityProvider per-stock 按需查询接口**:新建 `backend/data/data_quality.py`(严禁 `import backend.llm`,继承 P0-8 §2 红线 7);提供 `evaluate(stock_code: str, now: datetime) → DataQualityState` 单方法;每次调用按需聚合 7 信号源(staleness/divergence/quote_unavailable/minimum_freshness/news_outage/mirofish_unavailable/watchlist_snapshot_outage);无 watcher 缓存;fail-closed 偏保守(任一信号源查询失败即视为 breach);InstructionPlanBuilder 早返链中调用为第四种买卖类路由冻结来源(P0-8 §1.5 锁定)。

6. **daily_state on-demand 装配**:**不新增 `daily_trading_state` collection**;`InstructionPlanBuilder._assemble_daily_trading_state(trade_date, stock_code)` 按需从 P1-2.A `broker_events` collection(filter `ORDER_PLACED` / `ORDER_FILLED` 等)+ `watchlist_market_snapshots` 聚合生成 `@dataclass(frozen=True) DailyTradingState`(daily_new_instruction_count + daily_pnl + consecutive_loss_pnl_list + current_price);利用 P1-2.A broker_events 单一真相源(继承 P1-2.A §2 红线 2 append-only),避免单文档 mutation 与 P1-2.A frozen 原则冲突;13 codes × 5 单/日 ≈ 100 events/日的 filter 查询轻量。

7. **DataQualityState 7 字段 + 3 计数**:`@dataclass(frozen=True)` 共 10 字段;`is_acceptable_for_buy_sell` 属性聚合判定(`quote_unavailable` / `quote_staleness_breach` / `quote_divergence_breach` / `minimum_freshness_breach` 任一为真即不可买卖;`news_outage_breach` / `mirofish_unavailable` / `watchlist_snapshot_outage` 不阻断,但 EquityPoint 标 degraded);`degradation_reason` 属性返回 `+` 拼接 breach 列表(供 InstructionPlanBuilder 早返日志与飞书告警显示)。

#### 1.1.2 trading_hours gating(集合竞价 + 午休跳过)

```python
async def _run_intraday_mtm(self) -> None:
    """30s 触发;非交易日 / 集合竞价 / 午休跳过。"""
    today_sh = today_in_shanghai()
    if not self._holidays.is_trading_day(today_sh):
        return
    if not self._trading_hours.is_continuous_trading_now(now_in_shanghai()):
        # 跳过:09:00-09:25 集合竞价 / 09:25-09:30 收单 / 11:30-13:00 午休
        return
    try:
        equity_point = await self._compute_intraday_equity_point()
        await self._equity_repo.insert(equity_point)
        logger.debug("intraday_mtm_written", point_id=equity_point.point_id)
    except Exception as exc:
        logger.warning("intraday_mtm_write_failed", error=str(exc), exc_info=True)
        # 不阻断后续 cron;eod verify 兜底
```

`backend/data/trading_hours.py::is_continuous_trading_now(now)`:沪/深 A 股连续竞价时段 = `[09:30:00, 11:30:00) ∪ [13:00:00, 15:00:00)`;集合竞价不写 intraday EquityPoint(撮合未完成,价格不稳定)。

#### 1.1.3 三级价格回退路径

```python
async def _compute_intraday_equity_point(self) -> EquityPoint:
    positions = await self._broker.get_positions()
    cash = await self._broker.get_cash()
    frozen_cash = await self._broker.get_frozen_cash()
    last_event_id = await self._event_repo.get_latest_event_id()

    positions_mtm: list[PositionMTM] = []
    overall_quality = "normal"
    degradation_reasons: list[str] = []

    for pos in positions:
        snap, source, staleness = await self._resolve_mark_price(pos.code)
        # snap.close_price 是 mark_price;source ∈ {primary_adata, backup_akshare, last_known_cached}
        if source == "last_known_cached":
            overall_quality = "degraded"
            degradation_reasons.append(f"price_unavailable:{pos.code}")

        market_value = pos.volume * snap.close_price
        unrealized_pnl = market_value - pos.volume * pos.cost_price
        positions_mtm.append(PositionMTM(
            code=pos.code, volume=pos.volume, cost_price=pos.cost_price,
            mark_price=snap.close_price, market_value=market_value,
            unrealized_pnl=unrealized_pnl,
            price_source=source, staleness_seconds=staleness,
        ))

    positions_value = sum(p.market_value for p in positions_mtm)
    return EquityPoint(
        point_id=generate_point_id(),
        trade_date=today_in_shanghai().strftime("%Y-%m-%d"),
        captured_at=now_in_shanghai(),
        point_type="INTRADAY",
        cash=cash, frozen_cash=frozen_cash,
        positions_value=positions_value,
        total_equity=cash + frozen_cash + positions_value,
        positions=positions_mtm,
        mark_quality=overall_quality,
        degradation_reason="+".join(degradation_reasons) if degradation_reasons else None,
        last_broker_event_id=last_event_id,
    )

async def _resolve_mark_price(self, code: str) -> tuple[WatchlistSnapshot, str, int]:
    """三级回退:Redis ≤60s → Mongo ≤300s → last_known_cached(无年龄约束;degraded)。"""
    redis_snap = await self._snapshot_repo.get_latest_redis(code, max_age_seconds=60)
    if redis_snap is not None:
        return redis_snap, "primary_adata" if redis_snap.source == "adata" else "backup_akshare", redis_snap.age_seconds

    mongo_snap = await self._snapshot_repo.get_latest_mongo(code, max_age_seconds=300)
    if mongo_snap is not None:
        return mongo_snap, "primary_adata" if mongo_snap.source == "adata" else "backup_akshare", mongo_snap.age_seconds

    last_known = await self._snapshot_repo.get_last_known_cached(code)
    if last_known is None:
        raise IntradayMTMError(f"no_price_found_even_in_last_known_cache:{code}")
    return last_known, "last_known_cached", last_known.age_seconds
```

```python
class PositionMTM(BaseModel):
    """EquityPoint.positions 的子结构。per-position 明细(P1-2.B 锁定 per-position breakdown)。"""
    model_config = ConfigDict(frozen=True, strict=True, extra="forbid")

    code: str = Field(min_length=6, max_length=6, pattern=r"^\d{6}$")
    volume: int = Field(gt=0)
    cost_price: float = Field(gt=0.0)
    mark_price: float = Field(gt=0.0)
    market_value: float = Field(gt=0.0)
    """= volume * mark_price;Pydantic 校验确保 ≈ volume × mark_price(允许浮点 ε)"""
    unrealized_pnl: float
    """= market_value - volume * cost_price;可负"""
    price_source: Literal["primary_adata", "backup_akshare", "last_known_cached"]
    staleness_seconds: int = Field(ge=0)
    """price 距 captured_at 的年龄;last_known_cached 可能 > 60s"""
```

#### 1.2.2 EquityPoint 主体

```python
class EquityPoint(BaseModel):
    """equity_points collection 单条记录。intraday 30s + EOD verification + EOD fallback。"""
    model_config = ConfigDict(frozen=True, strict=True, extra="forbid")

    point_id: str = Field(pattern=r"^EP-\d{8}-\d{6}-\d{6}$")
    """格式 EP-{YYYYMMDD}-{HHMMSS}-{microseconds};单调递增,唯一索引"""

    trade_date: str = Field(pattern=r"^\d{4}-\d{2}-\d{2}$")
    captured_at: datetime  # tz-aware Asia/Shanghai
    point_type: Literal["INTRADAY", "EOD_VERIFICATION", "EOD_FALLBACK"]
    """INTRADAY = intraday_mtm cron 写入(30s)
       EOD_VERIFICATION = eod_pipeline verify 时已存在不需补写(此值仅记日志,不入 collection)
       EOD_FALLBACK = eod_pipeline verify 时 trade_date 无点,补写一条 degraded"""

    cash: float = Field(ge=0.0)
    frozen_cash: float = Field(ge=0.0)
    positions_value: float = Field(ge=0.0)
    total_equity: float = Field(ge=0.0)
    """= cash + frozen_cash + positions_value;Pydantic 校验确保 ≈ 等式(允许浮点 ε)"""

    positions: list[PositionMTM]
    """frozen list;按 code 升序"""

    mark_quality: Literal["normal", "degraded"]
    degradation_reason: str | None
    """+ 拼接的 breach 列表;normal 时为 None"""

    last_broker_event_id: str | None
    """反向索引到 P1-2.A broker_events.event_id;system init 时可空"""

    schema_version: int = 1
```

### 1.3 mark_quality='degraded' 详细判定

| 触发条件 | mark_quality | 处理 |
|---------|--------------|------|
| 任一持仓 code 走到三级回退 last_known_cached | degraded | EquityPoint 仍写入;degradation_reason 列出哪些 code |
| watchlist_snapshot 整批失败(全 watchlist Redis + Mongo 都断流) | degraded | 全持仓 last_known_cached;degradation_reason='watchlist_snapshot_outage' |
| EOD verify 时 trade_date 完全无点 | degraded | 写 EOD_FALLBACK 兜底;degradation_reason='no_intraday_point_for_trade_date' |
| 持仓为空 | normal | 不存在 mark price 问题 |

**禁止 cost_price fallback**:任何代码尝试将 `cost_price` 用作 `mark_price`(market_value = volume × cost_price)即视为红线违规;cost_price 不是市场状态。

#### 1.4.2 _step_verify_equity_point

```python
async def _step_verify_equity_point(self) -> None:
    """检查 trade_date 是否有 EquityPoint;无则补 EOD_FALLBACK degraded。"""
    today = today_in_shanghai().strftime("%Y-%m-%d")
    has_point = await self._equity_repo.exists_for_date(today)
    if has_point:
        logger.info("eod_verify_equity_point_ok", trade_date=today)
        return

    fallback = await self._compute_intraday_equity_point()
    fallback = fallback.model_copy(update={
        "point_id": generate_point_id(),  # 重新生成,因为 captured_at 微秒不同
        "point_type": "EOD_FALLBACK",
        "mark_quality": "degraded",
        "degradation_reason": "no_intraday_point_for_trade_date",
    })
    await self._equity_repo.insert(fallback)
    logger.warning("eod_fallback_equity_point_written", trade_date=today)
```

注意:`_step_verify_equity_point` 失败属于 P1-2.A §1.6.2 EOD chain 核心路径失败,1-retry → 仍失败 → freeze 次日买卖类(继承 `eod_pipeline_freeze` 第五种冻结源)。

```python
# backend/data/data_quality.py(P1-2.B 新增;严禁 import backend.llm)

from dataclasses import dataclass
from datetime import datetime

@dataclass(frozen=True)
class DataQualityState:
    """P0-8 §1.5.1 锁定:7 个 bool breach 字段 + 3 个计数字段 + is_acceptable + degradation_reason。"""

    # 7 breach 信号
    quote_unavailable: bool                # per-stock 主备都断
    quote_staleness_breach: bool           # 主源 staleness > 5s(P0-8 阈值)
    quote_divergence_breach: bool          # |主-备| / 主 > 0.3%(P0-8 阈值)
    minimum_freshness_breach: bool         # 未达 60s minimum_freshness_seconds_for_buy_sell
    news_outage_breach: bool               # 多域 5 源 0 alive(global)
    mirofish_unavailable: bool             # MiroFish service 超时(global)
    watchlist_snapshot_outage: bool        # 30s 快照 cron 断流(global)

    # 3 个计数
    primary_quote_age_seconds: int
    backup_quote_age_seconds: int
    news_sources_alive_count: int

    @property
    def is_acceptable_for_buy_sell(self) -> bool:
        """P0-8 §1.5 锁定:仅前 4 项 breach 阻断买卖类路由。"""
        return not any([
            self.quote_unavailable,
            self.quote_staleness_breach,
            self.quote_divergence_breach,
            self.minimum_freshness_breach,
        ])

    @property
    def degradation_reason(self) -> str | None:
        reasons: list[str] = []
        if self.quote_unavailable: reasons.append("quote_unavailable")
        if self.quote_staleness_breach: reasons.append(f"quote_staleness({self.primary_quote_age_seconds}s>5s)")
        if self.quote_divergence_breach: reasons.append("quote_divergence>0.3%")
        if self.minimum_freshness_breach: reasons.append("minimum_freshness<60s")
        if self.news_outage_breach: reasons.append(f"news_outage({self.news_sources_alive_count}/5)")
        if self.mirofish_unavailable: reasons.append("mirofish_unavailable")
        if self.watchlist_snapshot_outage: reasons.append("watchlist_snapshot_outage")
        return "+".join(reasons) if reasons else None
```

#### 1.5.2 DataQualityProvider per-stock 按需 evaluate

```python
class DataQualityProvider:
    """P1-2.B 锁定:per-stock evaluate;按需查询 7 信号源;无 watcher 缓存;严禁 import backend.llm。"""

    def __init__(
        self,
        market_data: MarketDataService,        # adata 主 + akshare 备
        snapshot_repo: WatchlistSnapshotRepo,  # P0-8 watchlist_market_snapshots
        news_repo: NewsRepo,                   # P0-8 多域 5 源 alive 计数
        mirofish: MiroFishService,             # MiroFish service health check
    ): ...

    async def evaluate(self, stock_code: str, now: datetime) -> DataQualityState:
        """13 codes × 5 单/日 调用量级,fail-closed 偏保守(任一查询失败视为 breach)。"""

        # 1. 主源 staleness(adata)
        try:
            primary_quote = await self._market_data.get_realtime_with_age(stock_code, source="adata")
            primary_age = primary_quote.age_seconds
            quote_staleness_breach = primary_age > 5
        except Exception:
            primary_age = -1  # sentinel
            quote_staleness_breach = True

        # 2. 备源 staleness(akshare)
        try:
            backup_quote = await self._market_data.get_realtime_with_age(stock_code, source="akshare")
            backup_age = backup_quote.age_seconds
        except Exception:
            backup_age = -1
            backup_quote = None

        # 3. quote_unavailable(主+备都断)
        quote_unavailable = primary_age < 0 and backup_age < 0

        # 4. divergence
        if primary_quote is not None and backup_quote is not None:
            divergence = abs(primary_quote.price - backup_quote.price) / primary_quote.price
            quote_divergence_breach = divergence > 0.003
        else:
            quote_divergence_breach = quote_unavailable  # 单源时按"无可比"保守视为 breach

        # 5. minimum_freshness
        minimum_freshness_breach = primary_age > 60 if primary_age >= 0 else True

        # 6. news_outage(多域 5 源)
        try:
            alive_count = await self._news_repo.count_alive_sources(now)
            news_outage_breach = alive_count == 0
        except Exception:
            alive_count = 0
            news_outage_breach = True

        # 7. mirofish
        try:
            mirofish_unavailable = not await self._mirofish.is_alive(timeout_seconds=5)
        except Exception:
            mirofish_unavailable = True

        # 8. watchlist_snapshot 断流(global)
        try:
            latest_snap_age = await self._snapshot_repo.get_oldest_among_watchlist_max_age(now)
            watchlist_snapshot_outage = latest_snap_age > 60  # 任一 code 快照 > 60s 即断流
        except Exception:
            watchlist_snapshot_outage = True

        return DataQualityState(
            quote_unavailable=quote_unavailable,
            quote_staleness_breach=quote_staleness_breach,
            quote_divergence_breach=quote_divergence_breach,
            minimum_freshness_breach=minimum_freshness_breach,
            news_outage_breach=news_outage_breach,
            mirofish_unavailable=mirofish_unavailable,
            watchlist_snapshot_outage=watchlist_snapshot_outage,
            primary_quote_age_seconds=max(0, primary_age),
            backup_quote_age_seconds=max(0, backup_age),
            news_sources_alive_count=alive_count,
        )
```

#### 1.6.2 _assemble_daily_trading_state 实现

```python
async def _assemble_daily_trading_state(
    self,
    trade_date: str,
    stock_code: str,
) -> DailyTradingState:
    """按需聚合 broker_events + watchlist_market_snapshots;无独立 daily_state collection。"""

    # 1. daily_new_instruction_count:今日 ORDER_PLACED 事件计数
    placed_events = await self._broker_event_repo.find(
        filter={
            "event_type": "ORDER_PLACED",
            "occurred_at": {"$gte": _trade_date_start_utc(trade_date), "$lt": _trade_date_end_utc(trade_date)},
        },
    )
    daily_new_instruction_count = len(placed_events)

    # 2. daily_pnl:今日已 FILLED 事件汇总 realized + 当前持仓 unrealized(从最近 EquityPoint 读)
    filled_today = await self._broker_event_repo.find(
        filter={
            "event_type": {"$in": ["ORDER_FILLED", "ORDER_PARTIALLY_FILLED"]},
            "occurred_at": {"$gte": _trade_date_start_utc(trade_date), "$lt": _trade_date_end_utc(trade_date)},
        },
    )
    realized = sum(_compute_realized_pnl(e, broker_state=self._broker.get_state()) for e in filled_today)

    latest_equity = await self._equity_repo.find_latest_for_date(trade_date)
    unrealized = (
        sum(p.unrealized_pnl for p in latest_equity.positions)
        if latest_equity is not None
        else 0.0
    )
    daily_pnl = realized + unrealized

    # 3. consecutive_loss_pnl_list:最近 3 笔 BUY→SELL closed pair 的 realized PnL
    consecutive_loss_pnl_list = await self._compute_last_n_closed_pair_pnls(n=3)

    # 4. current_price:从 watchlist_market_snapshots 读
    snap = await self._snapshot_repo.get_latest_redis(stock_code, max_age_seconds=60)
    if snap is None:
        snap = await self._snapshot_repo.get_latest_mongo(stock_code, max_age_seconds=300)
    current_price = snap.close_price if snap else None

    return DailyTradingState(
        daily_new_instruction_count=daily_new_instruction_count,
        daily_pnl=daily_pnl,
        consecutive_loss_pnl_list=consecutive_loss_pnl_list,
        current_price=current_price,
    )
```

#### 1.6.3 不引入 daily_trading_state collection 的理由

- P1-2.A `broker_events` collection 已是单一真相源;新增 `daily_trading_state` 会重复且需要 2-collection 一致性维护
- 单文档 mutation(per-trade_date doc 多字段增量更新)与 P1-2.A §2 红线 15 frozen Pydantic 原则冲突
- 13 codes × 5 单/日 ≈ 100 events/日的 Mongo filter 查询轻量(<10ms,RiskEngine 14-check 总耗时 < 50ms 仍有余量)

## 2. 红线(违反即停止)

1. **EquityPoint 写入入口红线**:任何代码尝试 `equity_points.insert_one` / `update_one` / `delete_one` 在 `backend/` 内只允许出现在 `backend/broker/persistence/equity_repo.py`(EquityRepo 内部);其他位置即红线违规。`update_one` / `delete_one` 在 EquityRepo 内也禁(append-only,继承 P1-2.A §2 红线 2 broker_events 模式)。

2. **cost_price 不可作 mark_price 红线**:`PositionMTM.mark_price = pos.cost_price` / `market_value = volume * cost_price` 视为红线违规;mark_price 必须来自三级回退之一;若 last_known_cached 也无,直接抛 `IntradayMTMError`(不写 EquityPoint 而非用 cost_price 兜底)。lint rule grep `mark_price\s*=\s*.*cost_price` 必为空。

3. **intraday_mtm cron 频率不可改红线**:30s 是 P1-2.B 锁定的频率,与 P0-8 §1.2 watchlist_snapshot 30s 同步;调整 cron `second="*/30"` 必须先走 `P1-2.B-amendment-{date}-mtm-cadence.md`;实施期 lint rule 阻止该字符串被覆写。

4. **trading_hours gating 红线**:`_run_intraday_mtm` 必须前置 `is_continuous_trading_now()` 检查;集合竞价(09:00-09:30)与午休(11:30-13:00)写 EquityPoint 即红线违规(撮合未完成,价格不稳定;P0-6 mark_quality 计算会失真)。

5. **三级回退路径不可绕过红线**:`_resolve_mark_price` 必须严格按"Redis ≤60s → Mongo ≤300s → last_known_cached"顺序;**禁止**直接调用 `market_data.get_realtime` 跳过 watchlist_snapshot collection(继承 P0-8 §1.5 single-source-of-truth 原则)。

6. **EOD verify_equity_point 不可跳过红线**:`_run_eod_pipeline` 必须包含 `_step_verify_equity_point` 调用;严禁 `if condition: skip verify` 任何形态;每 trade_date 必须有 EquityPoint(P0-6 §1.3.3 验收硬门槛 ≥1/日)。

7. **acceptance_report 必须读 EquityPoint 红线**:`backend/services/acceptance.py` 必须经 `equity_repo.find_latest_for_date(trade_date)` 读取(不允许 in-memory 计算 portfolio value);若 `find_latest_for_date` 返 None 即 acceptance 失败 → eod_pipeline 失败 → freeze 次日(继承 P1-2.A §2 红线 11)。

8. **DataQualityProvider LLM 隔离红线**:`backend/data/data_quality.py` 严禁 `import backend.llm.*` / `import backend.agents.*` / `import backend.mirofish.*`(继承 P0-8 §2 红线 7;P0-7 §2 红线 7;P1-2.A §2 红线 16);DataQualityProvider 内部仅依赖 `backend.data.market_data` / `backend.data.snapshot_repo` / `backend.data.news_repo` / `backend.mirofish.health_check`(后者是 health 检查不是仿真调用,作为 mirofish 子模块的非 LLM 接口)。

9. **DataQualityProvider per-stock 接口红线**:`evaluate(stock_code, now)` 是 P1-2.B 锁定唯一 public 方法;严禁新增 `evaluate_global(now)` 或 `snapshot(now)` 类方法(继承 P0-8 §1.5.1 per-stock granularity);若需要 global view,必须先走 amendment。

10. **DataQualityState 字段集不可改红线**:7 breach + 3 计数 + 2 property 共 12 个公开字段(继承 P0-8 §1.5.1 锁定结构);新增/删除字段必须走 `P1-2.B-amendment-{date}-data-quality-state-fields.md`;实施期 lint rule 阻止字段集修改。

11. **is_acceptable_for_buy_sell 仅 4 项 breach 阻断红线**:`quote_unavailable` / `quote_staleness_breach` / `quote_divergence_breach` / `minimum_freshness_breach` 任一为真即不可买卖;**禁止**把 `news_outage_breach` / `mirofish_unavailable` / `watchlist_snapshot_outage` 加入 `is_acceptable_for_buy_sell` 判定(继承 P0-8 §1.5 + P0-9 §2 红线 7 MiroFish 加分非核心);加入即红线违规(news_outage 期间不应阻断核心交易)。

17. **WatchlistSnapshot 三级回退年龄阈值不可改红线**:`max_age_seconds=60`(Redis)/ `max_age_seconds=300`(Mongo)在 P1-2.B 锁定;调整必走 amendment;两阈值同时 enforce — 60s 是热缓存边界,300s 是冷数据边界;超 300s 即走 last_known_cached 标 degraded。
